# autumn-design-system

Репозиторий документации дизайн-системы `autumn-ui`: текстовые спецификации,
токены и правила проектирования. Исходный код UI-кита здесь **не хранится** (он в
отдельном репозитории `autumn-ui`).

Цель — по этим материалам воссоздать виджеты и собрать новое приложение в единой
линейке, **не имея доступа ни к коду, ни к Figma**.

## Что внутри

| Каталог | Что это |
|---|---|
| `design-system/` | Спецификация UI-кита: основы, `components/<виджет>.md`, `tokens.json`. |
| `design-rules/` | Дизайн-код админ-приложений (уровень страниц, паттернов, оболочки). |
| `tokens/` | Исходный экспорт токенов (альфа-набор), вход для сборки `tokens.json`. |
| `_work/design-system/` | Внутреннее живое состояние: расхождения код ↔ Figma, скрипт сборки `tokens.json`, журнал Figma-вызовов. |

## С чего начать

- **Виджеты и токены** → `design-system/README.md`.
- **Страницы и паттерны приложений** → `design-rules/README.md`.
- **Конвенции и как работать в репозитории агенту** → `AGENTS.md`.

## Коротко о правилах

- Документация — на русском.
- Описываем **что видит пользователь**, а не как это устроено: без кода, имён
  классов, CSS и скриншотов; публичные имена виджетов и токенов — как есть.
- Числа точные, неподтверждённое помечается `UNKNOWN`.
- Источник истины — код, а не Figma; расхождения фиксируются во внутренних
  заметках (`AGENTS.md`).
