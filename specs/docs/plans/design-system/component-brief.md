# Шаблон брифа сессии по компоненту

Координатор заполняет и выдаёт сессии. Одна сессия — один компонент (файл
`design-system/components/<имя>.md`); для крупных — несколько сессий на части
(тогда «Объём сессии» сужается до подмножества виджетов/разделов файла).

---

## Бриф: <Компонент / файл спеки>

- **Файл спеки**: `design-system/components/<имя>.md`
- **Виджеты**: <имена>
- **Волна**: <1–5>
- **Зависимые спеки** (прочитать до кода): <список из sequencing.md>
- **Код-модули autumn-ui**: <модули/директории> (заполняет сессия при изучении)
- **Известные дыры на старте**: <секция «Не определено» файла + пункты из
  sequencing.md; пусто — «снять по coverage-checklist»>
- **Бюджет Figma**: ≤ <1–2> вызовов (остаток общего счётчика на момент старта)
- **Оценка**: <S / M / L>

### Обязательные шаги

1. Прочитать спеку + зависимые спеки + релевантные `foundations/`.
2. Пройти `coverage-checklist.md` (блоки A–I), выписать дельту.
3. Изучить код модуля (прямой доступ к файлам; `ai-grepa`, project `autumn-ui` —
   поиск). У факта спеки — источник `[код]`/`[Figma]`/`[вывод]`.
4. Figma — точечно по дельте; запись в `_work/design-system/ledger.md` **до** вызова.
5. Обновить спеку: разделы A–G, закрыть UNKNOWN, остаток → discrepancies (новый
   ID, `open`, план уточнения), переписать «Критерии соответствия».
6. Сайд-активность: выявленные общие правила — правка `design-system/foundations/`
   тем же коммитом (спорное — координатору).
7. Коммит: `<ветка> - <краткое англ. описание>`. Версию **не** поднимать.
8. Актуализировать свою строку в `tracking.md`: статус `готово`, остаток
   UNKNOWN, хеш коммита.

### Что НЕ делать

- Не менять инвентарь и публичные имена (components/README.md).
- Не править `tokens.json` руками; не выходить из репозитория; не трогать
  `.opencode/`.
- Не поднимать версию в README и не писать CHANGELOG.
- Не догадываться: нет подтверждения — `UNKNOWN` + discrepancies.

### Сдать

- Обновлённый файл спеки; записи в discrepancies; отчёт: закрытые пункты A–I +
  оставшиеся UNKNOWN + правки foundations (если были).

### Критерий готовности

Все пункты `coverage-checklist.md` для виджета закрыты (факт + источник) либо
явно в `discrepancies.md` со статусом и планом.
