# Прогресс по компонентам

Свою строку актуализирует **сессия** сразу после коммита (статус `готово`,
остаток UNKNOWN, коммит); координатор — статус `принято` и счётчик Figma.
Счётчик Figma-вызовов — единый на программу (≤ 50, потолок 60); фактические
вызовы — в `_work/design-system/ledger.md`.

## Счётчик Figma

- Использовано: **0** / 50 вызовов.
- Волна 5 сверяет остаток перед финалом.
