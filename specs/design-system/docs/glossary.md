## Назначение

Объясняет термины, которые используются во всех спецификациях. Каждый термин
означает одно и то же во всех файлах.

## Значения

### Темы и цвет

| Термин | Что значит |
|---|---|
| Light, Dark | две основные темы (атмосферы): светлая и тёмная |
| Атмосфера | светлая или тёмная тема области экрана; см. [Темы](foundations/themes.md) |
| Поверхность | уровень фона: основной (`primary`) или дополнительный (`secondary`) |
| Secondary, «справочно» | дополнительная поверхность; не рекомендуется; её значения приведены только для справки |
| Примитив | исходный цвет палитры, например gray 60 = `#79818B`; см. [Палитра](foundations/colors.md) |
| Роль (токен) | имя цвета для конкретного места, например `tooltip-background-color`; в таблицах «Цвета» — колонка «Роль» |
| Интент | смысловой цвет: `primary`, `secondary`, `success`, `danger`, `warning`, `info`, `dark`, `light`, `link` |
| Акцент | основной синий `#5D9AF4` или цвет интента |
| `#141F2F` 10 % | цвет с непрозрачностью 10 % |

### Размеры и текст

| Термин | Что значит |
|---|---|
| Размер `sm`, `m`, `lg` | размер виджета (S, M, L); `m` — по умолчанию; см. [Отступы и сетка](foundations/spacing.md) |
| `xxs`, `xs`, `xl` | устаревшие размеры; есть только у некоторых виджетов |
| Брейкпоинт `sm`, `md`, `lg`, `xl` | ширина экрана; не связан с размером виджета |
| Кегль | размер шрифта в px |
| Межстрочный | высота строки текста: в px или как отношение к кеглю (1,4286 = 20 / 14) |
| Начертание | толщина шрифта: 400 — обычный, 500 — средний, 700 — жирный |
| Отступ | расстояние от края элемента до его содержимого |
| Зазор | расстояние между соседними элементами |
| Радиус | скругление угла |
| Многоточие | текст, который не помещается, обрезается и заканчивается на «…» |

### Части виджетов

| Термин | Что значит |
|---|---|
| Слот | место для произвольного содержимого, которое задаёт приложение |
| Каркас формы | подпись над полем, строка статуса и пояснение под полем; см. [Form](components/form.md) |
| Чип | небольшой прямоугольник с текстом; см. [Tag](components/tag.md) |
| Грань | закрытый вид виджета выбора из списка: поле, кнопка или чип; см. [Selector](components/selector.md) |
| Панель | всплывающая поверхность со списком или содержимым |
| Якорь | элемент, рядом с которым появляется всплывающая панель |
| Оверлей | то, что появляется поверх страницы: поповер, подсказка, меню, модальное окно, боковая панель |
| Затемнение | полупрозрачный тёмный слой на весь экран под модальным окном или боковой панелью |
| Подложка | прозрачный слой на весь экран, который ловит клики вне панели |
| Тост | всплывающее уведомление в углу экрана |
| Контур фокуса | цветная обводка вокруг элемента, на котором стоит фокус клавиатуры |

### Состояния

| Термин | Что значит |
|---|---|
| Покой | обычный вид без взаимодействия |
| Hover | указатель мыши над элементом |
| Нажато | кнопка мыши или клавиша зажата на элементе |
| Фокус | элемент выбран для ввода с клавиатуры |
| Выбрано, «выбран» | элемент отмечен как выбранный и остаётся таким |
| Disabled | элемент недоступен: не реагирует на действия |
| Только чтение | значение видно, но его нельзя изменить |
| Валидация | цвета состояния поля: ошибка (`invalid`), предупреждение (`warning`), успех (`valid`) |
| Плейсхолдер | серая подсказка в пустом поле |
| «Уменьшить движение» | системная настройка, при которой анимации становятся мгновенными |
| `noBootstrap` | режим без оформления; см. [Кросс-виджетные режимы](foundations/widget-modes.md) |

### Пометки в документации

| Пометка | Что значит |
|---|---|
| `UNKNOWN` | значение не подтверждено; не придумывайте его |
| «из окружения» | виджет не задаёт значение сам: оно берётся у родителя или темы |
| «по умолчанию» | значение, если свойство не задано |

## Правила применения

- Если в тексте встречается непонятный термин, ищите его здесь.
- Новый термин сначала добавляется сюда, потом используется в спецификациях.
