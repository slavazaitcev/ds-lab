## Назначение

Описывает режимы, которые одинаково работают в нескольких виджетах.

## Значения

### Размер по умолчанию

| Что | Значение |
|---|---|
| Свойство | `size` |
| Значения | `sm` (S), `m` (M), `lg` (L) |
| По умолчанию | `m` |
| Устаревшие значения | `xxs`, `xs`, `xl` — не используются |

Исключение — тег: [Tag](../components/tag.md) и [TagInput](../components/tag-input.md)
принимают `xxs`, `xs`, `xl` и применяют их; [TagFilter](../components/tag-filter.md)
тоже принимает все шесть значений и сводит их к `sm` / `m` / `lg` для панели и
`xs` / `m` / `xl` для чипов внутри.

Действует для интерактивных виджетов: поле ввода, кнопка, тег, аватар, меню,
автодополнение, каркас формы.

### Режим без оформления — `noBootstrap`

| Что | Значение |
|---|---|
| Свойство | `noBootstrap` |
| Значения | вкл, выкл |
| По умолчанию | выкл |

Когда режим включён, у виджета пропадает:

- рамка и заливка;
- скругление углов;
- тень;
- обязательные внутренние отступы и минимальный размер;
- изменение кегля по размеру;
- цвет плейсхолдера;
- контур фокуса;
- вид hover и нажатия;
- вид disabled;
- цвета валидации.

Остаётся только содержимое. Примеры:

| Виджет | Вид в режиме `noBootstrap` |
|---|---|
| Поле ввода | текст без рамки |
| Кнопка | текст без заливки |
| Аватар | содержимое без диска |
| Меню | строки без карточки |

## Правила применения

- В режиме `noBootstrap` все размеры `sm` / `m` / `lg` выглядят одинаково.
  Исключение — боковая панель [Offcanvas](../components/offcanvas.md): у неё
  размеры продолжают работать.
- Собственные цвета виджета и цвета интентов пропадают. Остаются только цвета
  страницы: фон и цвет текста.
