## Назначение

Задаёт кривые, длительности анимаций и поведение при системной настройке
«уменьшить движение».

## Значения

### Кривые

Используются только стандартные именованные кривые.

| Кривая | Характер | Используется |
|---|---|---|
| `ease-in-out` | плавный разгон и плавное торможение | да |
| `ease-out` | быстрый старт, мягкая остановка | да |
| `ease` | мягкий разгон и торможение | да |
| `linear` | постоянная скорость | да |
| `ease-in` | медленный старт | нет |

Исключение — перетаскивание: своя кривая `cubic-bezier(0.25, 1, 0.5, 1)`.

### Анимации по типам

| Что движется | Длительность | Кривая | Что видит пользователь |
|---|---|---|---|
| Hover и фокус у кнопок, полей, ссылок, навигации, бейджей, тегов, фильтров | 0,15 с | `ease-in-out` | плавно меняются цвет, фон, рамка, тень |
| Стрелка раскрывающейся секции | 0,2 с | `ease-in-out` | стрелка поворачивается |
| Иконка внутри ссылки | 0,2 с | `ease-in-out` | иконка сдвигается вправо на ¼ кегля |
| Раскрытие и сворачивание секции | 0,35 с | `ease` | меняется только высота (или ширина у горизонтального варианта); без проявления и сдвига |
| Модальное окно (`Modal`) | мгновенно | — | окно и затемнение появляются и исчезают сразу |
| Поповер, подсказка, меню, панель автодополнения, уведомления | мгновенно | — | появляются и исчезают сразу |
| Галерея (`Lightbox`) | мгновенно | — | сцена появляется и исчезает сразу |
| Панель управления видеоплеера | 0,15 с | `ease-in-out` | панель и центральная кнопка плавно проявляются и гаснут |
| Изменение размера области видео в галерее | 0,55 с | `ease-in-out` | область видео плавно растёт или сжимается |
| Боковая панель (`Offcanvas`) | 0,3 с | `ease-in-out` | панель выезжает от края экрана; меняется только положение |
| Индикатор загрузки без процента | 0,667 с на оборот, бесконечно | `linear` | кольцо вращается; одинаково во всех встроенных индикаторах (кнопка, тег, выбор из списка) |
| Индикатор загрузки с процентом | 2 с на оборот | `linear` | кольцо вращается медленнее; при `percentNoRotation` не вращается |
| Пагинация | 0,15 с | `ease-in-out` | как hover и фокус |
| Перетаскивание: сдвиг соседних элементов | 0,25 с | `cubic-bezier(0.25, 1, 0.5, 1)` | соседи плавно раздвигаются; перетаскиваемый элемент следует за указателем без своей анимации |

Всё, чего нет в таблице, меняется мгновенно.

### Уменьшение движения

Система следует настройке операционной системы «уменьшить движение». Это
включено по умолчанию. Отдельного переключателя в интерфейсе нет.

Когда настройка включена:

| Что | Что происходит |
|---|---|
| Все анимации из таблицы | становятся мгновенными; конечное состояние то же |
| Индикатор загрузки без процента | «уменьшить движение» на вращение не влияет |
| Индикатор загрузки с процентом | не меняется |
| Плавная прокрутка к якорю | выключается; переход мгновенный |
| Мелкие переходы отдельных виджетов | не меняются |

### Глобальные выключатели

Через настройки виджетов анимации не включаются и не выключаются. Есть два
глобальных выключателя для всего приложения:

| Выключатель | По умолчанию | Что делает |
|---|---|---|
| «Выключить все анимации» | выкл | все анимации из таблицы убираются, циклы исчезают; конечные состояния те же |
| «Следовать системной настройке уменьшения движения» | вкл | если выключить, системная настройка не учитывается |

Настройки «замедлить анимации» нет.

## Правила применения

- Оверлеи (модальные окна, поповеры, подсказки, меню) появляются мгновенно.
  Единственный оверлей с анимацией — боковая панель.
