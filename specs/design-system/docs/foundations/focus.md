## Назначение

Задаёт, как выглядит элемент, на котором стоит клавиатурный фокус.

## Значения

| Что | Значение |
|---|---|
| Мягкое цветное свечение вокруг элемента | нет |
| Контур фокуса на контролах | 4 px |
| Контур фокуса на мелких стрелках пагинации | 2 px |
| Форма контура | повторяет форму элемента |
| Цвет контура | рамка фокуса полей ввода — `#5D9AF4` в обеих темах; контур контролов — по темам, см. таблицу ниже; значения по интентам — в разделе «Цвета» каждой спецификации |

Цвета контура по темам:

| Часть | Роль | Light | Dark |
|---|---|---|---|
| Рамка фокуса полей ввода: Input, TextArea, Selector, TagInput | `color-light-blue-100` | #5D9AF4 | #5D9AF4 |
| Контур фокуса кнопок primary, чипа Tag, кнопок пагинации | `color-light-blue-40` (Light) / `color-blue-dark-50` (Dark) | #BED6FB | #2C4162 |
| Контур фокуса чекбокса и переключателя | `color-light-blue-40` (Light) / `color-blue-dark-90` (Dark) | #BED6FB | #405D8E |
| Контур фокуса кнопок в группах (ButtonGroup) | `color-light-blue-40` (Light) / `color-light-blue-100` (Dark) | #BED6FB | #5D9AF4 |

## Правила применения

- У кнопок и чекбоксов контур рисуется снаружи элемента и не сдвигает соседние
  элементы.
- Контур показывается при переходе фокуса с клавиатуры (клавиша Tab). Показ по
  виджетам:

| Виджет | При клике мышью | В состоянии disabled |
|---|---|---|
| Поля ввода: Input, TextArea, Selector, TagInput | показывается (меняется цвет рамки) | нет |
| Кнопки (Button) | не показывается | нет |
| Чекбокс и переключатель | показывается | нет |
| Чип (Tag) | не показывается | нет |
| Кнопки в группах (ButtonGroup) | не показывается | нет |
| Кнопки пагинации (TablePager) | не показывается | нет |

### Сочетания

- **Фокус + ошибка.** Поле ввода с ошибкой при фокусе сохраняет рамку цвета
  ошибки: `#E61E43` (Light), `#E83556` (Dark); цвет рамки фокуса не
  показывается. Контур фокуса чекбокса с ошибкой — красный: `#F8BCC7` (Light),
  `#5D3048` (Dark). Контур фокуса чипа с ошибкой — красный: `#EB4B69` (Light),
  `#C13352` (Dark).
- **Фокус внутри группы.** Элемент с фокусом внутри группы (ButtonGroup,
  InputGroup) рисуется поверх соседних элементов: контур и рамка фокуса не
  перекрываются соседями.
- **Режим высокой контрастности.** Отдельного вида контура нет — контур
  остаётся как в обычном режиме.
