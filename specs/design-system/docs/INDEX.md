Текстовое описание дизайн-системы `autumn-ui`: основы, цвета, размеры и
спецификация каждого публичного виджета. Описано то, что пользователь видит и с
чем работает. По этому описанию виджет можно нарисовать в макете или собрать
заново и получить тот же вид и поведение, что в оригинале.

Для кого: дизайнер, разработчик интерфейса, ревьюер, языковая модель.

## Содержание

- [glossary.md](glossary.md) — словарь терминов всех файлов
- [foundations](foundations/INDEX.md) — основы: палитра, типографика, отступы,
  радиусы, тени, анимация, слои, фокус, иконки, темы, общие режимы
- [components](components/INDEX.md) — спецификации виджетов и инвентарь
  публичных имён

## Как читать

1. Незнакомый термин ищите в [Словаре](glossary.md).
2. Цвета, шрифт и отступы — в основах: [Палитра](foundations/colors.md),
   [Типографика](foundations/typography.md),
   [Отступы и сетка](foundations/spacing.md), [Темы](foundations/themes.md).
3. Под конкретную задачу откройте по описи
   [components/INDEX.md](components/INDEX.md) только нужные файлы.
4. Каждая спецификация виджета заканчивается разделом «Критерии соответствия» —
   чек-листом приёмки.

## Как устроен каждый файл

Каждый файл начинается с блока метаданных: название (`title`), краткое
содержание (`summary`), ситуации, когда файл читать (`read_when`), ключевые
слова (`keywords`) и связанные файлы (`related`). Заголовков первого уровня в
тексте нет. Заголовки разделов внутри файла не повторяются.

### Спецификация виджета

Каждая спецификация виджета в `components/` состоит из одних и тех же разделов в
одном порядке. Если раздел не нужен, в нём написано «Нет.».

| Раздел | Что в нём |
|---|---|
| Таблица в начале | виджеты в файле, класс, статус, от чего зависит |
| Назначение | что это и для чего |
| Состав | части виджета по порядку |
| Свойства | таблица: свойство, значения, значение по умолчанию, что меняется |
| Размеры | таблица: метрика × `sm`, `m`, `lg` |
| Состояния | таблица: состояние, что видит пользователь; приоритет состояний |
| Цвета | таблицы: часть, роль (токен), Light, Dark |
| Поведение | открытие, закрытие, анимация с длительностью и кривой, ввод |
| Клавиатура и скринридер | таблица: клавиша, действие; что объявляется |
| Граничные случаи | длинный текст, узкий экран, пустые данные |
| Дополнительные виджеты файла | если в файле несколько виджетов — по разделу на каждый |
| Не определено | значения, которые пока не подтверждены (`UNKNOWN`) |
| Критерии соответствия | чек-лист приёмки |

### Раздел спецификации в отдельном файле

Файл спецификации не длиннее 300 строк. Если раздел не помещается, он вынесен в
отдельный файл с именем `<виджет>-colors.md` (цвета) или `<виджет>-sizes.md`
(размеры). В основном файле в этом разделе стоит ссылка на отдельный файл. В
таблице в начале отдельного файла указано, какой раздел он содержит. Отдельный
файл заканчивается разделами «Не определено» и «Критерии соответствия» для
своего раздела.

### Файл основ

Каждый файл в `foundations/` состоит из разделов: Назначение, Значения, Правила
применения, Связанные разделы, Не определено.

## Как записаны значения

- Размеры — в px; один параметр — одна строка таблицы.
- Цвет — hex заглавными буквами (`#5D9AF4`) с ролью, если она известна.
  Непрозрачность — процентом (`#01070E` 70 %).
- Колонки Secondary — справочные; их статус описан в
  [Темы](foundations/themes.md).
- `UNKNOWN` — значение не подтверждено. Не придумывайте его.
