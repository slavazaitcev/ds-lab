## Назначение

Панель списка [Selector](selector.md) и её части: шапка с поиском, кнопки
создания, правки и удаления, строки значений. Панель всплывает над содержимым
страницы, когда выбор открыт.

## Состав

Сверху вниз:

1. **Строка поиска** — только при поиске в панели (`filterPlacement="dropdown"`).
   Поле с плейсхолдером «Поиск».
2. **Панель управления** — ряд кнопок-иконок. Под шапкой — линия 1 px.
3. **Форма создания** — когда нажата кнопка «Создать»: поле и кнопки «✓»
   (`ti ti-check`) и «✕» (`ti ti-x`).
4. **Список строк** — прокручивается. Углы списка подрезаются под радиус панели.

Кнопки панели управления по порядку:

1. «Очистить» (`ti ti-eraser`);
2. «Выбрать все» (`ti ti-select-all`) — только `multi`;
3. «Создать» (`ti ti-plus`) — если включено создание;
4. свои кнопки приложения.

Хотя бы одна кнопка видна всегда. Если других кнопок нет — видна «Очистить».
Кнопка — иконочная `icon-primary`; кнопка с текстом `text-primary` — только если
она одна.

### Строка списка: состав

Слева направо:

1. **Чекбокс** — только в `multi`. Это [Checkbox](checkbox.md) размера грани.
2. **Иконка** — в слоте 20 px.
3. **Метка** — квадрат с радиусом 4 px.
4. **Изображение** — круг.
5. **Произвольное содержимое.**
6. **Текст** — занимает оставшуюся ширину.
7. **Кнопки строки** справа — появляются при наведении: «карандаш» (`ti ti-edit`),
   «корзина» (`ti ti-trash`), свои кнопки. За кнопками — градиент-затухание цвета
   фона.

Особые строки:

- **Заголовок секции** — начертание 500 (раскрываемый заголовок — 400 с
  шевроном), без hover, не выбирается. Кнопки строки у него тоже появляются.
- **Вложенные строки** — отступ 12 px на каждый уровень. У раскрываемого
  родителя слева шеврон: `ti-chevron-down` (раскрыт) или `ti-chevron-right`
  (свёрнут, цвет `#79818B`).

## Свойства

Свойства панели задаются у [Selector](selector.md): минимальная ширина,
закреплённые строки, выбранные в начало, создание, правка, удаление,
«Выбрать все», чекбокс в строке, скрытие кнопок управления.

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| Покой | фон панели |
| Hover или активная с клавиатуры | серый фон; появляются кнопки строки; у снятого чекбокса — фон `#EFF5FE` и рамка `#5D9AF4` |
| Выбрана | бледно-синий фон |
| Выбрана + hover | более насыщенный бледно-синий фон |
| Disabled, только чтение | приглушена; курсор — стрелка; hover не работает; кнопки не появляются; контуров нет |
| Загрузка | индикатор по центру; hover без фона |
| Ошибка загрузки | текст ошибки по центру, ниже кнопка «Повторить» (цвет `#5D9AF4`, начертание 500) |
| Правка | вся строка заменена формой: поле и кнопки «✓», «✕»; рамки сверху и снизу 1 px; у соседних форм рамки не удваиваются |

## Поведение

### Где появляется панель

| Что | Значение |
|---|---|
| Сторона | снизу; если не помещается — сверху |
| Уровень слоя | 1050 |
| Анимация | нет; как у [Popover](popover.md) |

### Поиск в панели

Список фильтруется через 200 мс после ввода.

### Создание, правка, удаление

| Действие | Как запускается | Что происходит |
|---|---|---|
| Создать | «Создать» в панели управления | открывается форма в шапке (поле, «✓», «✕») или действие приложения; пока ждём — индикатор на кнопке. Созданное значение выбирается |
| Изменить | «карандаш» в строке | строка заменяется формой или запускается действие приложения; пока ждём — индикатор на кнопке |
| Удалить | «корзина» в строке | значение удаляется сразу. С подтверждением меню: слева от кнопки появляется меню с пунктом «Удалить»; удаление — после выбора пункта. Пока ждём — индикатор. Удалённое значение снимается с выбора |

- «✓» активна, только если текст не пустой и изменился. «✕» — отмена.
- После успеха форма закрывается, фокус возвращается.

## Клавиатура и скринридер

В строке поиска:

| Клавиша | Действие |
|---|---|
| Печатные символы | фильтр |
| ↓ | к первой строке |
| ↑ | остаться в поиске |
| Space | вводит пробел; не открывает и не выбирает |

В списке:

| Клавиша | Действие |
|---|---|
| ↓, ↑ | по строкам, без перехода с последней на первую; ↑ на первой строке — к панели управления; ↑ на панели управления — к грани или поиску |
| Enter | `single` — выбрать и закрыть; `multi` — переключить; на кнопке — нажать |
| ←, → | по кнопкам строки, затем по кнопкам панели управления |
| Escape | закрыть; в форме — отменить |

- Кнопки не входят в порядок Tab. Контур фокуса — только с клавиатуры.
- Строка объявляется как пункт списка; объявляются выбор, disabled и «только
  чтение».
- Панель управления объявляется панелью инструментов.
- Кнопки объявляются с именами: «Очистить», «Выбрать все», «Создать»,
  «Редактировать», «Удалить». Подсказки кнопок — при наведении и фокусе.
- Для скринридера есть скрытая кнопка закрытия.

## Граничные случаи

- В узкой колонке панель не шире грани, список прокручивается внутри.
- Длинный текст строки переносится. Сводка «, » обрезается многоточием.
- На сенсорных экранах hover нет, поэтому кнопки строки без наведения не
  появляются.

## Не определено

Нет.

## Критерии соответствия

- [ ] Панель: снизу, при нехватке места сверху; отступ 8 px от грани и от краёв;
      слой 1050; минимальная ширина 240 px; не шире грани; радиус 6 / 8 / 8 px;
      тень по таблице.
- [ ] Высота строки 32 / 36 / 40 px; панель не выше 8 строк + поиск + панель
      управления + 1 px.
- [ ] Строка: чекбокс (`multi`), иконка 20 px, метка 12 / 14 / 14 px, изображение
      28 / 32 / 32 px, текст; кнопки строки при hover с затуханием.
- [ ] Цвета строки по таблице; заголовок 500 без hover.
- [ ] Пустое состояние: 3 строки высотой, «Нет значений», без кнопок.
- [ ] «Очистить», «Выбрать все», «Создать» в панели управления; «карандаш» и
      «корзина» в строках; подтверждение меню слева от кнопки.
