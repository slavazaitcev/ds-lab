## Назначение

- `InputNumber` — поле для числа.
- `InputMoney` — поле для денежной суммы с фиксированным числом знаков после
  точки.

Оба поля выглядят как [InputText](input.md). Стрелок изменения значения, знака
валюты, разделителей разрядов и выравнивания вправо нет.

## Состав

Как у [InputText](input.md).

## Свойства

Общие свойства полей — в [InputText](input.md). Свойства `InputNumber`:

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `mode` | `int`, `float` | `int` | можно ли вводить точку |
| `allowNegative` | вкл, выкл | выкл | можно ли вводить минус в начале |
| Минимум и максимум | числа | нет | допустимый диапазон |
| Число цифр целой и дробной части | числа | нет | ограничение длины |
| Сброс при переполнении | вкл, выкл | выкл | при выходе за ограничение значение сбрасывается |

Свойства `InputMoney`:

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `subunitLength` | целое число от 0 | 2 | число знаков после точки (0 — без дробной части; 4 — например, для криптовалют) |

Состояния как у [InputText](input.md). Дополнительно:

Как у [InputText](input.md).

## Поведение

- Вводятся только цифры, одна точка и, если разрешено, минус в начале. Другие
  символы не вводятся; остаётся последнее допустимое значение.
- Запятая сразу заменяется точкой.
- В режиме `float` промежуточные значения вроде «12.» и «42.00» видны во время
  ввода. При уходе фокуса нули в конце и точка перед ними убираются: «42.00»
  становится «42». Одиночная точка без нулей остаётся: «12.» не меняется.
- `InputMoney` — это `InputNumber` в режиме `float`. После точки можно ввести не
  больше `subunitLength` знаков.

## Клавиатура и скринридер

Как у [InputText](input.md). Недопустимые символы с клавиатуры не вводятся.

## Граничные случаи

- Значение за пределами ограничения длины сбрасывается, если включён сброс при
  переполнении.

## Не определено

Нет.

## Критерии соответствия

- [ ] `InputNumber` и `InputMoney` выглядят как `InputText`.
- [ ] Запятая заменяется точкой; недопустимые символы не вводятся.
- [ ] «42.00» → «42» при уходе фокуса; «12.» остаётся.
- [ ] `InputMoney`: после точки не больше `subunitLength` знаков (по умолчанию 2).
- [ ] Пока число набирается, цвет состояния и сообщение скрыты.
