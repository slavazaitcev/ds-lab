## Назначение

Экран фатального сбоя. Показывается вместо приложения, когда оно не может
работать дальше. На экране: картинка, успокаивающий заголовок, кнопка
перезапуска, необязательная кнопка «скачать файл отладки» и сводка ошибки.

«Синий экран» — только название: синего фона нет.

`BSOD` обычно показывается автоматически при сбое части приложения. Для этого
есть невидимый технический слой `ErrorBoundary`, своего вида у него нет.

## Состав

Экран занимает всю ширину и высоту родителя и заменяет содержимое приложения.
Это не оверлей и не модальное окно. Своих фона, рамки, тени и скругления нет:
виден фон страницы.

Внутри — колонка по центру экрана. Сверху вниз:

1. **Картинка** — квадрат 200 × 200 px. Выступает вверх на 50 px. Можно заменить
   своей.
2. **Заголовок** — кегль 24 px, начертание 500, без отступов. Цвет — цвет текста
   страницы.
3. **Кнопки** в ряд, ширина каждой по содержимому:
   1. «Перезагрузить приложение» — всегда;
   2. «Скачать файл отладки» — только если приложение умеет отдавать файл.
4. **Сводка ошибки** — заголовок и описание. Слева вертикальная линия 2 px.

До и после заголовка, до и после кнопок, до и после сводки можно вставить своё
содержимое.

## Состояния

Экран неподвижен, своих состояний нет. Кнопки — состояния
[Button](button.md).

| Ситуация | Что видит пользователь |
|---|---|
| Нет описания ошибки | в сводке только заголовок |
| Нет скачивания файла | одна кнопка |

## Поведение

- Экран появляется и исчезает сразу, без анимации.
- «Перезагрузить приложение» сразу выполняет перезапуск, без подтверждения. По
  умолчанию перезагружает страницу.
- «Скачать файл отладки» запускает скачивание; индикатора нет.
- Сводка всегда развёрнута. Если она не помещается, прокручивается по вертикали.
- Длинные слова в описании переносятся; пробелы сохраняются.

### Когда показывается

Если часть приложения падает при отображении, эта часть заменяется экраном
сбоя, а ошибка записывается в журнал. Вернуться к рабочему виду можно только
перезапуском. Ошибки в реакциях на действия пользователя и в фоновых операциях
так не перехватываются.

## Клавиатура и скринридер

| Клавиша | Действие |
|---|---|
| Tab | переход между кнопками |
| Enter, Space | нажать кнопку |

- Фокус на экран не переходит автоматически и не удерживается.
- Заголовок экрана объявляется заголовком.
- Сводка читается как обычный текст.
- Появление экрана не объявляется.

## Граничные случаи

- На узком экране колонка сужается; заголовок и описание переносятся.
- Колонка не выше 80 % экрана; длинная сводка прокручивается внутри.

## Не определено

Нет.

## Критерии соответствия

- [ ] Экран на всю область, колонка по центру; своего фона, рамки, тени нет.
- [ ] Колонка: до 680 px шириной, до 80 % высоты, поля 16 px.
- [ ] Порядок: картинка 200 × 200 px с выступом 50 px, заголовок 24 px 500,
      кнопки (зазор 8 px, сверху 16 px, снизу 24 px), сводка (линия 2 px, отступы
      12 px и 4 px).
- [ ] Сводка: заголовок 14 / 22 px 500, описание 12 px; без описания — только
      заголовок; прокрутка при переполнении.
- [ ] «Перезагрузить приложение» есть всегда; «Скачать файл отладки» — только
      при скачивании; подтверждения нет.
- [ ] Картинку можно заменить; вставки до и после блоков.
- [ ] Цвета: картинка `#79818B` / `#C5C9CD`, текст сводки `#5F6772` /
      `#C5C9CD`, линия `#9298A0`.
- [ ] Тексты на трёх языках; заголовок можно заменить.
- [ ] Анимаций нет; фокус не переносится.
