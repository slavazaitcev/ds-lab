## Назначение

Контрол выбора с подписью. Один виджет, три вида:

| `variant` | Вид | Для чего |
|---|---|---|
| `checkbox` | квадрат с галочкой | выбрать несколько вариантов |
| `radio` | круг с точкой | выбрать один вариант из нескольких |
| `switch` | дорожка с ползунком | включить или выключить |

Отдельных виджетов `Radio` и `Switch` нет.

## Состав

Одна горизонтальная строка, выровненная по центру:

```
[ отметка ] [ отступ ] [ подпись (+ звёздочка) ] [ ⓘ ]
[ сообщение или пояснение — строкой ниже, с отступом под отметку ]
```

1. **Отметка** — квадрат, круг с точкой или дорожка с ползунком. Фиксированный
   размер. Системного вида браузера не видно.
2. **Подпись** — одна строка, обрезается многоточием. Звёздочка обязательного
   поля в конце, цвет ошибки. Необязательная.
3. **Значок справки ⓘ** — в строке подписи, с подсказкой. Необязательный.
4. **Сообщение или пояснение** — строкой ниже. Отступ слева = ширина отметки +
   отступ подписи (у `switch` — ширина дорожки + отступ подписи).

Отметка: фон прозрачный, рамка 1 px, тени нет.

| Вид | Скругление |
|---|---|
| Квадрат `checkbox` | 4 px |
| Круг `radio` | 50 % |
| Дорожка `switch` | полное (таблетка) |

## Свойства

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `variant` | `checkbox`, `radio`, `switch` | `checkbox` | вид отметки |
| `size` | `sm`, `m`, `lg` | `m` | размер отметки и подписи |
| Значение | снят, отмечен, неопределён | снят | вид отметки, см. «Состояния» |
| `isInline` | вкл, выкл | выкл | несколько чекбоксов в строку с зазором 16 px |
| Зеркально | вкл, выкл | выкл | отметка справа, подпись слева |
| `withTooltip`, `tooltip` | выкл, вкл, текст | выкл | подсказка при наведении и фокусе |
| `disabled` | вкл, выкл | выкл | приглушённый вид; не переключается |
| `readonly` | вкл, выкл | выкл | вид обычный; не переключается |

| `isValid`, `isInvalid`, `isWarning` | вкл, выкл | выкл | цвета валидации отметки |

## Состояния

### Значение

| Значение | `checkbox` | `radio` | `switch` |
|---|---|---|---|
| Снят | пустой квадрат с рамкой | пустой круг | серая дорожка, белый ползунок слева |
| Отмечен | заливка и белая галочка | цветная рамка, прозрачный фон, цветная точка | цветная дорожка, ползунок справа |
| Неопределён | заливка и белый прочерк | нет такого состояния | заливка и белая короткая полоска по центру |

### Взаимодействие

| Состояние | Что видит пользователь | Курсор |
|---|---|---|
| Покой | цвета по таблице «Цвета» | рука |
| Hover | бледная заливка и синяя рамка у снятого | рука |
| Нажато | как «отмечен» | рука |
| Фокус с клавиатуры | синяя рамка и контур 4 px; контур не сдвигает соседей | рука |
| Disabled | отметка приглушена до 50 %, подпись — до 60 %; не переключается | стрелка |
| Только чтение | вид как обычно; не переключается | рука |
| Валидация | рамка, заливка, точка, бледная заливка при hover и контур — цвета состояния; подпись не меняет цвет | рука |

Disabled сильнее hover, фокуса и нажатия. Цвета валидации сильнее обычных.

## Поведение

### Отметки

| Отметка | Как выглядит |
|---|---|
| Галочка `checkbox` | две линии, толщина штриха 3, круглые концы, белая |
| Прочерк `checkbox` | горизонтальная линия, толщина штриха 3, белая |
| Точка `radio` | при отметке 16 px точка около 8 px в диаметре; заливка цвета акцента, без обводки |
| Ползунок `switch` | при дорожке 36 × 20 px ползунок около 15 px в диаметре |
| Полоска `switch` (неопределён) | белый прямоугольник со скруглением, по центру дорожки |

### Анимация

- `checkbox` и `radio` переключаются мгновенно.
- У `switch` двигается только ползунок слева направо: 150 мс, `ease-in-out`.
  При системной настройке «уменьшить движение» — мгновенно.

### Переключение

- Переключает клик по отметке и клик по подписи.
- В disabled и «только чтение» переключение не работает.

### Подсказка

Показывается при наведении и фокусе. Вид — как у [Tooltip](tooltip.md).

## Клавиатура и скринридер

| Клавиша | Действие |
|---|---|
| Tab | фокус на отметку; появляется контур |
| Space | переключить (срабатывает один раз) |
| Enter | переключить |
| Стрелки | ничего; перехода между чекбоксами нет |

- Скринридер объявляет вид по `variant`: флажок, переключатель-радио или
  переключатель.
- Имя — подпись. Обязательность объявляется.
- Состояния «отмечен» и «неопределён» объявляются.

## Граничные случаи

- Подпись в одну строку, обрезается многоточием. Несколько строк в подписи
  невозможны. При нехватке места строка целиком переносится.
- С `isInline` чекбоксы идут в строку с зазором 16 px.

## Не определено

Нет.

## Критерии соответствия

- [ ] Один виджет, три вида: квадрат с галочкой, круг с точкой, дорожка с
      ползунком. По умолчанию `checkbox`, размер `m`.
- [ ] Отметка 16 × 16 px (`sm`, `m`, `lg`); дорожка 30 × 16, 36 × 20,
      36 × 20 px; рамка 1 px; скругление 4 px, 50 %, таблетка.
- [ ] Отступ подписи 6 / 8 / 8 px; кегль 13 / 14 / 14 px; межстрочный
      16 / 20 / 20 px; минимальная высота строки 20 / 20 / 20 px.
- [ ] Снятая отметка: рамка `#B0B4BA` / `#79818B`; hover — заливка `#EFF5FE` /
      `#233045` и рамка `#5D9AF4`; отмеченная — заливка и рамка `#5D9AF4`,
      галочка белая.
- [ ] Фокус с клавиатуры — контур 4 px `#BED6FB` / `#405D8E`, рамка `#5D9AF4`.
- [ ] Disabled: отметка 50 %, подпись 60 %; цвета по таблице; курсор — стрелка.
- [ ] «Только чтение» выглядит как обычно и не переключается.
- [ ] `switch`: ползунок ходит на 14 / 16 / 16 px за 150 мс `ease-in-out`;
      неопределён — белая полоска по центру.
- [ ] Валидация окрашивает рамку, заливку, бледную заливку при hover, контур и
      точку по таблице; подпись не меняет цвет.
- [ ] Space и Enter переключают; клик по подписи тоже переключает.
- [ ] `isInline` — зазор 16 px; сообщение строкой ниже с отступом под отметку.
