## Назначение

Поля ввода.

| Виджет | Для чего |
|---|---|
| `InputText` | однострочный текст |
| `InputTextArea` | многострочный текст; отличия — в [InputTextArea](input-textarea.md) |
| `InputNumber` | число; отличия — в [InputNumber и InputMoney](input-number.md) |
| `InputMoney` | денежная сумма с фиксированным числом знаков после точки; отличия — в [InputNumber и InputMoney](input-number.md) |

Все четыре выглядят одинаково. У `InputNumber` и `InputMoney` нет стрелок
изменения значения, знака валюты, разделителей разрядов и выравнивания вправо.
Отличаются только допустимые символы и то, как значение приводится к виду при
уходе фокуса.

## Состав

Сверху вниз (см. [Form](form.md)):

1. **Подпись** — необязательная; может быть звёздочка обязательного поля и
   значок справки ⓘ.
2. **Поле.**
3. **Строка статуса** `Feedback` — если есть сообщение.
4. **Пояснение** `HelperText` — скрыто, пока показан `Feedback`.

Зазор подпись — поле и поле — сообщение: 6 px.

Внутри поля слева направо:

1. **Иконки слева** — любое число. Необязательные.
2. **Значение** или плейсхолдер.
3. **Иконки справа** — любое число. Необязательные.
4. **Кнопка очистки** «✕» — последняя справа, только когда есть значение.
   Необязательная.

Детали:

- **Поле** — прямоугольник на всю ширину колонки. Рамка 1 px. Фон залит. Тени
  нет ни в одном состоянии. Текст по центру по высоте. Шрифт Roboto, начертание
  400, межбуквенный интервал обычный.
- **Иконка** занимает слот во всю высоту поля и шириной 20 px; иконка 20 px по
  центру слота. Зазор между слотами 8 px.
- **Отступ текста от края** при иконках = число иконок × 20 px + зазоры между
  ними + боковой отступ поля. Пример для `m` с одной иконкой слева:
  20 + 8 + 11 = 39 px.
- **Минимальная ширина поля** с иконками = слоты слева + слоты справа + 24 px под
  текст + 2 px рамки.
- **Кнопка очистки** — иконка `ti ti-x` (можно заменить).
- Каретка и цвет выделения текста — браузерные.

## Свойства

Свойства общие для `InputText`, `InputTextArea`, `InputNumber` и `InputMoney`.
Свойства только многострочного и числовых полей — в их файлах.

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `size` | `sm`, `m`, `lg` | `m` | высота, отступы, кегль, радиус |
| `placeholder` | строка | нет | серая подсказка в пустом поле |
| `icons` | список иконок; для каждой — сторона (слева или справа), действие, disabled, «только чтение», подсказка | нет | иконки в поле; иконка с действием — кнопка, без действия — декоративная |
| `withClear` | выкл, вкл, имя иконки | выкл | кнопка очистки «✕» справа |
| `isPlaintext` | вкл, выкл | выкл | нет рамки и фона, боковые отступы 0; высота, кегль и отступы сверху и снизу остаются |
| `withTooltip` | выкл, вкл (текст = значение), текст | выкл | подсказка при наведении и фокусе |
| `mask` | готовые маски или своё правило | нет | ограничивает ввод, см. «Поведение» |
| `disabled` | вкл, выкл | выкл | поле не реагирует |
| `readonly` | вкл, выкл | выкл | значение нельзя изменить; фокус возможен |
| `required` | вкл, выкл | выкл | красная звёздочка после подписи |
| `trimValueOnBlur` | вкл, выкл | выкл | при уходе фокуса пробелы по краям убираются (только `InputText`) |
| `autoFocus` | вкл, выкл | выкл | курсор в поле при первом показе |
| `isInvalid`, `isWarning`, `isValid` | вкл, выкл | выкл | цвета ошибки, предупреждения, успеха |
| `feedback`, `feedbackType` | сообщение или список; тип сообщения | нет | сообщение под полем; без явного флага тип сообщения задаёт цвет поля |
| `hideFeedback` и его варианты | вкл, выкл | выкл | сообщение и цвета состояния скрыты: всегда, до первого взаимодействия или пока значение не изменено |
| `isNowTypesetting` | вкл, выкл | выкл | пока идёт набор, цвета состояния и сообщение скрыты; возвращаются после ухода фокуса |
| `noBootstrap` | вкл, выкл | выкл | режим без оформления, см. [Кросс-виджетные режимы](../foundations/widget-modes.md) |

## Состояния

### Поле

| Состояние | Что видит пользователь |
|---|---|
| Покой | фон и рамка одного цвета, тени нет |
| Hover | поле не меняется; меняются только иконки-кнопки |
| Фокус | рамка `#5D9AF4`; плейсхолдер светлеет; фон и текст не меняются; свечения и тени нет. Фокус с клавиатуры и с мыши выглядят одинаково |
| Disabled | вид как в покое, но всё поле с непрозрачностью 60 %; ввод, нажатия и клавиши не работают; кнопка очистки видна, но не реагирует; курсор — стрелка |
| Только чтение | вид как в покое; ввод и очистка не работают; фокус возможен |
| Ошибка, предупреждение, успех | рамка цвета состояния, фон — бледный оттенок состояния |
| Состояние + фокус | рамка остаётся цветом состояния, фон становится обычным; после ухода фокуса оттенок фона возвращается |
| Состояние + disabled или «только чтение» | цветная рамка и оттенок фона сохраняются; в disabled всё поле с непрозрачностью 60 % |
| Пусто | серый плейсхолдер; при фокусе светлеет |

Своего состояния загрузки у поля нет. Загрузку показывают составные виджеты,
например [Selector](selector.md) и [Autocomplete](autocomplete.md).

### Иконки

| Вид иконки | Состояние | Что видит пользователь |
|---|---|---|
| Декоративная | любое | цвет иконки; не реагирует; курсор текстовый; контура нет |
| Кнопка | hover | цвет наведения; курсор — рука |
| Кнопка | нажато | цвет нажатия |
| Кнопка | фокус с клавиатуры | контур 4 px, радиус контура 4 px |
| Любая | disabled или «только чтение» (у иконки или у поля) | цвет декоративной иконки; курсор — стрелка; нажатие не работает |

Кнопка очистки в disabled и «только чтение» ведёт себя так же: видна, не
реагирует.

### Приоритет состояний

1. **Между цветами состояния:** ошибка сильнее предупреждения, предупреждение
   сильнее успеха.
2. **Поле и группа:** состояние самого поля сильнее состояния группы полей. Если
   у поля задан хотя бы один из трёх флагов (даже выключенный), состояние группы
   к полю не применяется. Поле без флагов получает состояние группы.
3. **Флаги и сообщение:** явные флаги сильнее типа сообщения. Если флагов нет,
   цвет задаёт сообщение и его тип; тип по умолчанию — ошибка. Без текста
   сообщения цвета нет.
4. **Скрытие:** `hideFeedback` и его варианты убирают и текст, и цвет, даже если
   флаг задан.
5. **Фокус:** см. «Состояние + фокус». Исключение — «только чтение» в фокусе:
   сохраняются и рамка, и оттенок фона.
6. **Идёт набор** (`isNowTypesetting` или незавершённое число): цвет и сообщение
   скрыты до ухода фокуса.

## Поведение

### Ввод

- Значение меняется сразу при вводе.
- Enter, Escape и стрелки работают как обычно: стрелки двигают курсор, Enter
  отправляет форму.
- Нажатие на иконку-кнопку выполняет её действие.
- Кнопка «✕» очищает поле; это считается изменением значения.
- Клик по подписи ставит фокус в поле (см. [Form](form.md)).

### Маски (`mask`)

Готовые маски:

| Маска | Варианты |
|---|---|
| Телефон | по стране; строгий и нестрогий |
| Дата | — |
| Время | — |
| Дата и время | — |
| IPv4, IPv6 | полный и короткий; с подсетью |
| Порт | с минимумом и максимумом |
| MAC-адрес | — |
| Диапазон | две маски через разделитель |

Можно задать своё правило. Плейсхолдер маски виден всегда и по мере ввода
заменяется символами. Недопустимый символ не вводится.

### Анимация

- Рамка и фон меняются за 0,15 с `ease-in-out`.
- Цвет плейсхолдера и иконок меняется мгновенно.
- При системной настройке «уменьшить движение» переход мгновенный.

### Полоса прокрутки однострочного поля

У однострочного поля полоса прокрутки браузерная. Полоса прокрутки
многострочного поля описана в [InputTextArea](input-textarea.md).

## Клавиатура и скринридер

| Клавиша | Действие |
|---|---|
| Tab | фокус в поле |
| Shift+Tab | уход из поля |
| Печатные символы | ввод (с учётом маски и числовых ограничений) |
| Backspace, Delete | удаление символов |
| Enter, Escape, стрелки | стандартное поведение браузера |
| Tab на иконке-кнопке | иконки-кнопки входят в порядок Tab |
| Enter, Space на иконке-кнопке | не срабатывают; иконка-кнопка нажимается только кликом |

- Контур фокуса есть только у иконок-кнопок, не у декоративных иконок.
- Поле объявляется как стандартное поле ввода; плейсхолдер и признак
  обязательности объявляются.
- Сообщение объявляется через каркас формы: ошибка — сразу, предупреждение и
  успех — мягко (см. [Form](form.md)).
- Подсказка доступна при фокусе.
- Иконка-кнопка объявляется кнопкой; имя задаётся приложением.

## Граничные случаи

- В узкой колонке с иконками первым сжимается текст (минимум 24 px).
- Длинный плейсхолдер обрезается многоточием.
- Длинное значение прокручивается внутри поля по горизонтали.
- Маски дат, времени и телефона учитывают формат и страну.
- На сенсорных экранах поведение стандартное: курсор, прокрутка, долгое нажатие.
- В режиме `noBootstrap` пропадают рамка, заливка, скругление, подсветка фокуса,
  отступы.

## Критерии соответствия

- [ ] Порядок сверху вниз: подпись, поле, `Feedback`, `HelperText`; зазоры 6 px.
- [ ] Порядок в поле: иконки слева, значение, иконки справа, «✕» последней.
- [ ] Высота 32 / 36 / 40 px; `m` по умолчанию.
- [ ] Отступ слева и справа 9 / 11 / 11 px; сверху и снизу 7 / 7 / 9 px.
- [ ] Кегль 13 / 14 / 14 px; межстрочный 16 / 20 / 20 px; радиус 6 / 8 / 8 px;
      рамка 1 px; тени нет.
- [ ] Иконка 20 px в слоте во всю высоту; зазор 8 px; отступ текста по формуле;
      минимум 24 px под текст.
- [ ] Фокус: рамка `#5D9AF4`, без свечения; плейсхолдер светлеет; переход 0,15 с.
- [ ] Hover не меняет поле; иконки-кнопки меняют цвет, курсор — рука.
- [ ] Disabled — как покой, но всё поле с непрозрачностью 60 %, курсор — стрелка; «только чтение» — как покой.
- [ ] Цвета состояний по таблице; приоритет: ошибка, предупреждение, успех; в
      фокусе рамка цветная, фон обычный.
- [ ] Поле с флагом не получает состояние группы; `hideFeedback` и
      `isNowTypesetting` скрывают сообщение и цвет.
- [ ] «✕» появляется только при значении; в disabled и «только чтение» видна, но
      не реагирует.
- [ ] `isPlaintext` убирает рамку, фон и боковые отступы.
- [ ] Иконка-кнопка получает фокус с Tab, нажимается только кликом, контур 4 px.
