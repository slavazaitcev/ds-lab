## Назначение

Основа всех всплывающих панелей. `Popover` решает, где и когда появится панель
рядом с якорем и как она закрывается. Вид панели задаёт виджет, который на нём
построен: [Tooltip](tooltip.md), [Menu](menu.md), [Autocomplete](autocomplete.md),
[Selector](selector.md), [Calendar](calendar.md).

| Виджет | Что это |
|---|---|
| `Popover` | всплывающая панель у якоря |
| `MaybePopover` | то же с выключателем `withoutPopover`: содержимое показывается на месте, без всплывания |
| `PopoverBoundary` | невидимая область: панели внутри неё не выходят за её границы |
| `PopoverBoundaryReset` | отменяет такую область для вложенного содержимого |
| `FloatingArrow` | треугольная стрелка от панели к якорю |

## Состав

1. **Панель** — без своего фона, рамки, радиуса, тени и отступов (прозрачная).
   Текст: начертание 400, межстрочный 1,42857, перенос строк, выравнивание по
   началу; кегль — из окружения.
2. **Стрелка** — необязательная. Треугольник 20 × 20 px с закруглённой вершиной.
   Указатель на неё не реагирует.
3. **Подложка** — необязательная. Прозрачный слой на весь экран, который ловит
   клики.
4. **Скрытая кнопка закрытия** — для скринридера, 1 × 1 px, текст «Dismiss».

## Свойства

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `placement` | `top`, `bottom`, `left`, `right`, каждая с `-start` или `-end` | `bottom` | сторона якоря |
| `placements` | список сторон | подбор автоматически | запасные стороны по порядку |
| `enableClick` | выкл, вкл; режим `main` или `context`; привязка `element` или `pointer` | выкл | открытие по клику |
| `enableHover` | выкл, вкл; задержки | выкл | открытие при наведении |
| `enableFocus` | выкл, вкл | выкл | открытие при фокусе на якоре |
| `withArrow` | выкл, вкл, свой цвет | выкл | стрелка |
| `withBackdrop` | выкл, вкл | выкл | прозрачная подложка на весь экран |
| `closeOnEscape` | выкл, вкл | выкл | закрытие по Escape |
| `closeOnBackdrop` | выкл, вкл | выкл | закрытие по клику вне якоря и панели |
| `closeOnReferenceNotVisible` | выкл, вкл | выкл | закрытие, когда якорь ушёл из видимой области |
| `withListNavigation` | выкл, вкл | выкл | переход по строкам стрелками |
| `withListTypeahead` | выкл, вкл | выкл | набор букв переходит к подходящей строке |
| `withFocusManager` | выкл, вкл | автоматически | фокус переходит в панель |
| Ограничение размера панели (`withContentSize`) | минимальная и максимальная ширина и высота: число, «доступное место», «как у якоря» | нет | панель не выходит за заданные размеры |
| Отступы | см. «Размеры» | см. «Размеры» | положение панели |
| Скрытая кнопка закрытия | выкл, вкл, свой текст | вкл, «Dismiss» | кнопка для скринридера |
| `disableAllFeatures` | вкл, выкл | выкл | все способы открытия выключены, открытая панель закрывается |
| `withoutPopover` (`MaybePopover`) | вкл, выкл | выкл | содержимое показывается на месте |
| `noBootstrap` | вкл, выкл | выкл | без базового текстового оформления панели |

Значения по умолчанию для способов открытия:

| Способ | Параметр | По умолчанию |
|---|---|---|
| Клик | режим | `main` (левый клик) |
| Клик | привязка | `element` (весь якорь) |
| Клик | без мыши | выкл; вкл, если включено открытие при наведении |
| Клик | без клавиатуры | выкл |
| Наведение | задержка открытия | 500 мс |
| Наведение | открытие после остановки курсора | 250 мс |
| Наведение | без открытия при фокусе | выкл |
| Фокус | любой фокус, не только клавиатурный | выкл |

## Размеры

| Метрика | По умолчанию |
|---|---|
| Зазор от якоря | 4 px |
| Зазор от якоря со стрелкой | 12 px (4 + 8 на стрелку) |
| Сдвиг вдоль якоря | 0 px |
| Отступ стрелки от краёв панели | 4 px |
| Отступ от краёв допустимой области | 0 px |
| Стрелка | 20 × 20 px; выступает на 12 px за панель |
| Уровень слоя панели и подложки | 1050 |

Поворот стрелки: снизу от якоря — без поворота; сверху — 180°; слева — 90°;
справа — −90°.

Все размеры от темы не зависят. Размеров `sm`, `m`, `lg` нет.

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| Скрыта | панели нет |
| Показана | панель у якоря |
| Активная строка | при навигации по строкам; сбрасывается при закрытии |

Hover, фокус, disabled, загрузку и ошибку описывает виджет, построенный на
`Popover`.

## Цвета

| Часть | Light | Dark |
|---|---|---|
| Панель | прозрачная | прозрачная |
| Подложка | прозрачная | прозрачная |
| Стрелка по умолчанию | `#000000` | `#000000` |

Цвет стрелки задаёт виджет, который её использует. Например, у подсказки цвет
стрелки — цвет фона подсказки.

## Поведение

### Где появляется панель

1. Сначала пробуется `placement`.
2. Затем стороны из `placements` по порядку.
3. Если `placements` не задан — сначала противоположная сторона, потом стороны
   поперёк. Для `bottom`: `top`, затем `right`, затем `left`.
4. Если не помещается нигде — выбирается сторона с наименьшим выходом за край,
   с приоритетом верх и низ.
5. Для языков с письмом справа налево стороны поперёк меняются местами.

Панель сдвигается внутрь допустимой области, если иначе выходит за край.
Положение пересчитывается при прокрутке, изменении размера окна и изменении
якоря.

### Открытие

| Способ | Как работает |
|---|---|
| Клик, `main` | левый клик, Enter или Space по якорю открывает; повторный — закрывает |
| Клик, `context` | правый клик, долгое касание или клавиша контекстного меню |
| Привязка `element` | панель привязана ко всему якорю |
| Привязка `pointer` | панель привязана к точке клика |
| Наведение | панель открывается через 500 мс после наведения; если курсор двигается по якорю — через 250 мс после остановки. Включает и открытие при фокусе |
| Фокус | панель открывается при фокусе на якоре с клавиатуры |

На сенсорных экранах панель открывается касанием, без задержек.

Панель появляется сразу, без анимации.

### Закрытие

| Способ | Как работает |
|---|---|
| Повторный клик по якорю | закрывает |
| Курсор ушёл с якоря (при наведении) | закрывает сразу. Если курсор движется к панели, есть «безопасная зона»: можно перевести курсор на панель, и она не закроется. Уход с панели закрывает |
| Escape | если включено `closeOnEscape` |
| Клик вне якоря и панели | если включено `closeOnBackdrop`; нажатие и отпускание вне обоих; срабатывает только у последней открытой панели |
| Клик по подложке | закрывает, если это включено; иначе подложка только не даёт нажимать на страницу под ней |
| Якорь ушёл из видимой области | если включено `closeOnReferenceNotVisible` |
| Фокус ушёл из якоря и панели | если удерживается фокус |
| Действие приложения | закрывает эту панель или всю цепочку вложенных |

Панель исчезает сразу. Фокус после закрытия на якорь не возвращается.

### Вложенные панели

Панель внутри панели образует цепочку. Закрытие верхней панели закрывает её
вложенные панели. Клик вне срабатывает только у последнего уровня. Подложки
ложатся поверх страницы в порядке открытия.

### Размер панели

Без ограничения размера панель не ограничена и длинные слова не переносит.
Переносы и прокрутку задаёт виджет, построенный на `Popover`.

## Клавиатура и скринридер

| Клавиша | Действие |
|---|---|
| Tab | фокус на якорь (если включено открытие по клику или фокусу) |
| Enter, Space | открыть или закрыть (`main`) |
| Клавиша контекстного меню | открыть (`context`) |
| Escape | закрыть (если включено) |
| Стрелки | переход по строкам (если включена навигация по строкам) |
| Буквы | переход к строке, которая начинается с набранного (если включено); набор сбрасывается через 750 мс паузы |

- Навигация по строкам может идти вертикально, горизонтально или в обе стороны,
  по колонкам, с переходом по кругу или без. Подсветка может быть виртуальной:
  фокус не переносится.
- Удержание фокуса слабее, чем у [Modal](modal.md): начальный фокус — на панели,
  фокус можно увести наружу.
- Роль панели для скринридера задаёт виджет, построенный на `Popover`
  (например, подсказка).
- Стрелка скрыта от скринридера.
- Есть скрытая кнопка закрытия «Dismiss».
- Анимаций нет, настройка «уменьшить движение» не влияет.

## Граничные случаи

- Нет места — панель переходит на другую сторону и сдвигается внутрь области.
- `MaybePopover` с `withoutPopover` показывает содержимое как обычный блок: без
  всплывания и без способов открытия.

## Не определено

Нет.

## Критерии соответствия

- [ ] Своего фона, рамки, радиуса, тени и отступов у панели нет; текст 400,
      межстрочный 1,42857; уровень 1050.
- [ ] По умолчанию: сторона `bottom`, зазор 4 px (12 px со стрелкой), сдвиг 0,
      отступ стрелки 4 px, отступ от краёв 0.
- [ ] Подбор стороны: `placement`, затем `placements`, затем противоположная и
      стороны поперёк (для `bottom`: `top`, `right`, `left`).
- [ ] Открытие: клик (`main`, `context`; `element`, `pointer`), наведение
      (500 мс, 250 мс после остановки, закрытие сразу с безопасной зоной), фокус.
- [ ] Escape и клик вне по умолчанию выключены; клик вне срабатывает только у
      последнего уровня.
- [ ] Появление и исчезновение мгновенные.
- [ ] Стрелка 20 × 20 px с закруглённой вершиной, выступает на 12 px, цвет — от
      виджета (по умолчанию чёрный).
- [ ] Навигация по строкам и переход по буквам (сброс 750 мс) — по включению;
      фокус на якорь после закрытия не возвращается.
- [ ] Вложенные панели закрываются вместе с родительской.
- [ ] `withoutPopover` показывает содержимое на месте.
