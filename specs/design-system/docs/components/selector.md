## Назначение

Выбор одного или нескольких значений из списка. Закрытый виджет показан
«гранью» — полем, кнопкой или чипом. По нажатию открывается всплывающая панель
со списком.

| Виджет | Грань |
|---|---|
| `SelectorInput` | поле ввода |
| `SelectorButton` | кнопка |
| `SelectorTag` | чип |
| `Selector` | грань задаёт приложение |

Восемь готовых граней для сборки своего выбора описаны в
[Грани SelectorReference*](selector-reference.md).

Панель списка и её части описаны в [SelectorDropdown](selector-dropdown.md).

Режимы: `single` — одно значение; `multi` — ноль или больше значений.

## Состав

1. **Грань** — видна всегда. Стоит в каркасе формы: подпись, грань, `Feedback`,
   `HelperText` (см. [Form](form.md)).
2. **Панель** — всплывает над содержимым страницы, когда виджет открыт.

Части, размеры, состояния и цвета грани — в
[Грани SelectorReference*](selector-reference.md). Части, размеры, состояния и
цвета панели — в [SelectorDropdown](selector-dropdown.md).

## Свойства

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `size` | `sm`, `m`, `lg` | `m` | размер грани, строк, панели |
| Тип значения | `single`, `multi` | нет (обязателен) | один или несколько выбранных |
| `filterPlacement` | `none`, `dropdown`, `reference` | `none` | где поиск: нет, в панели, в грани |
| Задержка поиска | мс | 200 мс | через сколько после ввода фильтруется список |
| `buttonVariant` (грань-кнопка) | `outlined`, `filled`, `text`, `none`, свой набор по состояниям | `outlined` | вид кнопки; варианты — в [Грани SelectorReference*](selector-reference.md) |
| Кнопка без вида «нажата» (`buttonWithoutToggle`) | вкл, выкл | выкл | кнопка не выглядит нажатой при открытой панели |
| Порог сводки в поле | выкл, число | выкл | после скольких значений чипы сворачиваются в одну строку |
| Порог счётчика в чипе | выкл, число | выкл | после скольких значений появляется «+остаток» |
| Выбранные в начало списка | вкл, выкл | `multi` — вкл; `single` — выкл | при открытии выбранные строки стоят первыми |
| Закреплённые строки сверху | список | нет | строки всегда вверху списка |
| Создание, правка, удаление | вкл, выкл для каждого | выкл | кнопки «Создать», «карандаш», «корзина» |
| Подтверждение удаления меню (`confirmBy="menu"`) | вкл, выкл | выкл | удаление после второго подтверждения |
| «Выбрать все» | вкл, выкл | выкл | кнопка в панели управления (`multi`) |
| Не закрывать после выбора (`single`) | вкл, выкл | выкл | панель остаётся открытой |
| Закрывать после выбора (`multi`) | вкл, выкл | выкл | панель закрывается после выбора |
| Чекбокс в строке | вкл, выкл | вкл для `multi` | чекбокс слева в строке |
| Автовыбор единственного значения | вкл, выкл | выкл | если доступно одно значение, оно выбирается |
| Автоснятие исчезнувшего значения | вкл, выкл | выкл | выбранное значение снимается, если его нет в данных |
| Не сбрасывать поиск после выбора | вкл, выкл | выкл | поиск остаётся после изменения значения |
| Минимальная ширина панели (`minWidthPx`) | px | 240 px | панель не уже этого значения |
| Скрыть все кнопки управления, скрыть «Очистить» | вкл, выкл | выкл | состав панели управления |
| `withTooltip`, `tooltip` | выкл, вкл, текст | выкл | подсказка грани |
| `withoutPopover` | вкл, выкл | выкл | панель показывается на месте, без всплывания |
| `disabled`, `readonly` | вкл, выкл | выкл | см. «Состояния» |
| `isInvalid`, `isWarning`, `isValid` | вкл, выкл | выкл | цвета валидации грани |
| `noBootstrap` | вкл, выкл | выкл | снимает оформление грани и панели |

Вид строк, выбранных значений, недопустимых значений и пустого состояния
можно задать свой.

## Поведение

### Открытие

- Клик по грани, Enter или Space на грани.
- У грани-поля клик ставит фокус в поле.
- При поиске в грани ввод текста тоже открывает панель.
- Фокус после открытия: в строку поиска (поиск в панели) или в поле грани.
- При открытии список прокручен к началу.

### Закрытие

- Клик вне панели.
- Escape — фокус возвращается на грань.
- Выбор значения в режиме `single`.
- Уход фокуса из панели.
- Повторный клик по грани.

При закрытии поиск очищается.

### Выбор

- **`single`.** Выбранная строка подсвечена. Клик по строке выбирает значение и
  закрывает панель. Чекбоксов нет.
- **`multi`.** В строках чекбоксы. Клик переключает значение. Панель остаётся
  открытой. Выбранные значения на грани — чипы, сводка или счётчик.
- После изменения значения поиск сбрасывается.

### Поиск

Список фильтруется через 200 мс после ввода.

Где появляется панель, создание, правка и удаление значений — в
[SelectorDropdown](selector-dropdown.md).

## Клавиатура и скринридер

На грани:

| Клавиша | Действие |
|---|---|
| Enter, Space | открыть панель |
| ↓, ↑ | открыть и перейти к первой строке (при поиске в панели); при поиске в грани — движение от поля |
| Tab | уйти; пока панель открыта, фокус остаётся в панели |

Клавиши строки поиска и списка — в [SelectorDropdown](selector-dropdown.md).

- Кнопки не входят в порядок Tab. Контур фокуса — только с клавиатуры.
- Disabled-грань не получает фокус с Tab.
- Строка объявляется как пункт списка; объявляются выбор, disabled и «только
  чтение».

## Граничные случаи

- Тексты интерфейса берутся из строк приложения. Языки: русский, английский,
  французский.

| Текст | ru | en | fr |
|---|---|---|---|
| Пусто | Не выбрано | Not selected | Non sélectionné |
| Нет значений | Нет значений | No values | Aucune valeur |
| Поиск | Поиск | Search | Recherche |

Также переводятся: «Очистить», «Выбрать все», «Создать», «Редактировать»,
«Удалить», «Повторить», «Выбрано N».

- В режиме `noBootstrap` снимается оформление грани и панели: рамка, заливка,
  скругление, отступы, цвет фокуса.

## Не определено

Нет.

## Критерии соответствия

- [ ] Грань и всплывающая панель; режимы `single` и `multi`.
- [ ] Клавиши — по таблицам; Escape закрывает и возвращает фокус на грань.
- [ ] Поиск через 200 мс после ввода; очищается при закрытии.
- [ ] `noBootstrap` снимает оформление грани и панели.
