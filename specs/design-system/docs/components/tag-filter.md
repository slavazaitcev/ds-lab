## Назначение

Панель фильтров над таблицей или списком. Каждое условие фильтра показано
чипом. Через поле ввода пользователь добавляет и меняет условия. Нажатие на чип
открывает редактор этого условия.

## Состав

Сверху вниз: подпись, панель, строка статуса `Feedback`, пояснение `HelperText`
(см. [Form](form.md)).

Части панели слева направо:

1. **Кнопка «плюс»** (иконка `ti ti-plus`). Переводит фокус в поле ввода (если
   поля нет — на последний чип) и открывает список фильтров.
2. **Чипы условий** — в порядке добавления, в одну строку.
3. **Поле ввода** — без рамки, прозрачное, растягивается. Плейсхолдер по
   умолчанию «Поиск».
4. **Дополнительные кнопки-иконки** — свои кнопки приложения. Необязательные.
5. **Крестик «очистить всё»** (иконка `ti ti-x`) — только если есть удаляемые
   условия.
6. **Разделитель** 1 px во всю высоту — только если есть кнопка «применить».
7. **Кнопка «применить»** (по умолчанию лупа `ti ti-search`). Необязательная.

Когда чипы не помещаются, у краёв ряда появляются градиенты-затухания с
кнопками-шевронами (`ti ti-chevron-left`, `ti ti-chevron-right`). Полоса
прокрутки не видна.

Панель — прямоугольник на всю ширину колонки. Рамка 1 px цвета фона. Тени нет ни
в одном состоянии. Курсор над всей панелью — текстовый. Клик по пустому месту
панели переводит фокус в поле ввода (или на последний чип).

### Чип условия

Чип показывает «Название: значение».

- Название — начертание 500.
- Значение — начертание 400.
- Зазор между ними — 2 px.
- Обе части обрезаются многоточием и не переносятся.
- У удаляемого условия — крестик.

## Свойства

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `size` | `sm`, `m`, `lg` | `m` | размер панели и чипов |
| `placeholder` | текст | «Поиск» | плейсхолдер пустой панели |
| `placeholderIfNotEmpty` | текст | как `placeholder` | плейсхолдер, когда условия есть |
| `disabled` | вкл, выкл | выкл | панель не реагирует; цвета обычные |
| `readonly` | вкл, выкл | выкл | вид обычный; панель не реагирует |
| `noBootstrap` | вкл, выкл | выкл | режим без оформления, см. [Кросс-виджетные режимы](../foundations/widget-modes.md) |

Для каждого условия можно:

- изменить вид чипа (любые настройки [Tag](tag.md)), значки и пункты списка;
- показать дополнительную всплывающую панель на время правки;
- запретить удаление (крестика не будет).

Язык по умолчанию — русский. Доступны русский, английский и французский.

### Типы условий

| Тип | Чип в покое | Редактор |
|---|---|---|
| Flag (флаг) | название + «Да» или «Нет» | список из двух вариантов под чипом, ширина ровно 240 px; при нехватке места — над чипом. Выбор применяется сразу. Повторный выбор текущего значения снимает условие |
| Text (текст) | название + текст | чип становится полем: фон прозрачный, рамка 1 px `#5D9AF4`. Если при выходе текст пустой, чип удаляется |
| Wildcard (маска) | лупа + текст, без названия | как Text. В панели не больше одного такого условия |
| Number (число) | название + число | как Text, но поле числовое; число форматируется при вводе. Пусто при выходе — чип удаляется |
| Date (дата) | название + дата в формате `dd.MM.yyyy`; для вариантов с временем добавляется `, HH:mm` или `, HH:mm:ss` | поле даты в чипе; клик по чипу открывает [Calendar](calendar.md) под чипом (зазор 8 px, при нехватке места — над чипом). Выбор дня применяется сразу. «Очистить» удаляет условие. Закрытие со значением сохраняет его. Недоступные дни погашены |
| Date range (диапазон дат) | название + «от – до» через короткое тире | как Date, но поле и календарь диапазона |
| Selector, один выбор | название + выбранный вариант | список шириной от 240 до 420 px под чипом (при нехватке места — над чипом). Выбор применяется и закрывает список. Может быть поиск по списку |
| Selector, несколько | как один выбор, значения накапливаются; может быть счётчик | тот же список с множественным выбором; остаётся открытым. Закрытие с выбором сохраняет условие, без выбора — удаляет |

Счётчик в чипе Selector: высота 20 px, минимальная ширина равна высоте, отступ
6 px, полностью скруглён, текст белый.

## Размеры

Шкала панели шире общей шкалы контролов. Внутри панели чипы используют размеры
чипа [Tag](tag.md) `xs`, `m`, `xl` — устаревшие для прямого использования ступени,
применяемые только внутри [TagInput](tag-input.md) и этой панели: `xs` для `sm`,
`m` для `m`, `xl` для `lg`.

| Метрика | `sm` | `m` (по умолчанию) | `lg` |
|---|---|---|---|
| Высота панели | 28 px | 36 px | 44 px |
| Радиус панели | 4 px | 8 px | 8 px |
| Отступ панели слева и справа | 2 px | 4 px | 7 px |
| Кегль | 13 px | 14 px | 16 px |
| Межстрочный | 16 px | 20 px | 20 px |
| Зазор между чипами | 2 px | 4 px | 8 px |
| Поле ввода: минимальная ширина | 360 px | 420 px | 520 px |
| Панель: минимальная ширина | 369 px | 435 px | 538 px |
| Кнопка-иконка: иконка | 16 px | 20 px | 24 px |
| Кнопка-иконка: контур фокуса | 2 px | 3 px | 3 px |
| Кнопка-иконка: радиус контура | 3 px | 4 px | 4 px |
| Зазор между кнопками-иконками | 8 px | 8 px | 12 px |
| Чип: высота | 22 px | 28 px | 28 px |
| Чип: кегль | 13 px | 14 px | 16 px |
| Чип: отступ слева и справа | 6 px | 8 px | 8 px |
| Чип: минимальная ширина поля правки | 24 px | 30 px | 30 px |
| Поле создания условия: ширина | 360 px | 420 px | 520 px |
| Крестик чипа: иконка | 16 px | 16 px | 16 px |

Минимальная ширина панели = минимальная ширина поля + отступы панели.

Крестик чипа: отступ 4 px, зона нажатия около 24 px.

## Состояния

### Панель

| Состояние | Что видит пользователь |
|---|---|
| Покой | фон и рамка одного цвета; тени нет |
| Hover | ничего не меняется |
| Фокус внутри панели или открыт список | рамка `#5D9AF4`; плейсхолдер светлеет |
| Disabled | цвета обычные (панель не тускнеет); курсор — стрелка; нажатия и клавиши не работают; контуров нет; чипы не реагируют; фокус снимается |
| Только чтение | вид обычный; взаимодействие заблокировано |

Цвета валидации (`invalid`, `warning`, `valid`) на чипы не переходят.
Индикатора загрузки у виджета нет.

### Чип

| Состояние | Что видит пользователь |
|---|---|
| Покой | инвертированный фон, см. «Цвета» |
| Hover | фон темнее |
| Открыт редактор Flag, Selector, Date, Date range | вид «выбран» |
| Открыт редактор Text, Number, Wildcard | вид правки: прозрачный фон, рамка `#5D9AF4` |
| Фокус с клавиатуры | контур 2 px; контур только у одного чипа с фокусом |

### Кнопки-иконки

| Состояние | Что видит пользователь |
|---|---|
| Покой, hover, нажато | цвет иконки по таблице «Цвета» |
| Фокус с клавиатуры | контур по таблице «Размеры» |
| Disabled и «только чтение» | цвет покоя, курсор — стрелка, нажатие не работает |

Disabled и «только чтение» сильнее hover. Контур фокуса — только при навигации с
клавиатуры.

## Поведение

### Добавление условия

1. Фокус в поле ввода или нажатие «плюса» открывает список фильтров под полем.
   Список выровнен по левому краю, отстоит от поля на 5 px вниз и не ближе 8 px
   к краю экрана. Ширина — от 360 px до ширины панели, но не больше 520 px.
2. В списке — фильтры, которые ещё не добавлены. Список фильтруется по мере ввода
   сразу, без задержки.
3. Если есть фильтр-маска (Wildcard), набранный текст показан отдельной строкой
   внизу списка, после разделителя, с лупой. Выбор этой строки или Enter сразу
   создаёт условие с этим текстом.
4. Выбор другого фильтра (мышью; ↑ / ↓ и Enter; или точное имя фильтра и Enter,
   регистр не важен) заменяет поле ввода редактором нового условия.
5. Escape в редакторе нового условия отменяет создание и возвращает поле ввода.

Тексты-заглушки списка:

| Ситуация | Текст |
|---|---|
| Нет доступных фильтров | «Нет доступных фильтров» |
| Доступна только маска | «Введите текст для поиска» |

Список виден и когда фильтров нет, и когда совпадение одно. Вид и клавиши
списка — как у [Autocomplete](autocomplete.md).

Плейсхолдер «Поиск» на других языках: «Search» (английский), «Recherche»
(французский).

### Правка условия

- Вход в правку — клик по чипу (все типы). Для Text, Number и Wildcard — также
  Enter при фокусе на чипе.
- Поле правки получает фокус и растёт по ширине текста.
- Выход — Enter, Escape или клик вне редактора (зависит от типа, см. таблицу
  «Типы условий»).

### Прокрутка ряда чипов

- Нажатие на шеврон сдвигает ряд примерно на один чип.
- Чип с фокусом всегда прокручивается в видимую область. Сдвиг больше 50 px —
  плавный, меньше — мгновенный.

### Анимация

| Что | Длительность | Кривая |
|---|---|---|
| Рамка и фон панели | 0,15 с | `ease-in-out` |
| Кнопки-иконки | 0,1 с | `ease-in-out` |
| Фон, рамка, тень чипа | 150 мс | `ease-in-out` |
| Цвет текста, плейсхолдера, иконок | мгновенно | — |

При системной настройке «уменьшить движение» всё мгновенно.

## Клавиатура и скринридер

Tab входит в панель, фокус попадает в поле ввода (или на последний чип). Внутри
панели фокус переходит между полем и чипами; фокус есть только у одного чипа.
Tab из поля и Shift+Tab выходят из панели. При уходе фокуса наружу выбор чипа
снимается.

В поле ввода:

| Клавиша | Действие |
|---|---|
| Печатные символы | фильтруют список |
| ↑, ↓ | по строкам списка, без перехода с последней на первую |
| Enter | выбрать строку списка |
| ← | к последнему чипу |
| Backspace при пустом поле | к последнему чипу |
| Escape | ничего не делает; в редакторе нового условия — отменяет создание |

На чипе:

| Клавиша | Действие |
|---|---|
| ←, → | к соседнему чипу; с последнего — в поле ввода |
| Home, End | первый, последний чип |
| Enter | открыть редактор (Text, Number, Wildcard); в редакторе — подтвердить |
| Escape | в редакторе — выйти |
| Backspace, Delete | удалить чип, фокус на предыдущий (или в поле, если чип был последним) |
| Печатные символы | фокус в поле ввода |

- Панель объявляется как контейнер; в disabled — недоступной.
- Кнопки-иконки и крестик чипа объявляются кнопками.
- Значение условия читается как текст чипа.
- Редакторы объявляются как [Selector](selector.md) и [Calendar](calendar.md),
  список фильтров — как [Autocomplete](autocomplete.md).

## Граничные случаи

- В узкой колонке ряд чипов прокручивается внутри панели; видны градиенты с
  шевронами.
- Длинные названия и значения обрезаются многоточием, не переносятся.
- Тексты интерфейса («Поиск», «Да», «Нет», заглушки списка) берутся из строк
  приложения; даты — по языку, см. [Calendar](calendar.md).
- Редакторы открываются во всплывающих панелях, см. [Popover](popover.md).
  Список фильтров появляется без анимации и без стрелки.
- На сенсорных экранах hover нет.

## Не определено

Нет.

## Критерии соответствия

- [ ] Порядок частей: «плюс», чипы, поле ввода, свои кнопки, «очистить всё»,
      разделитель 1 px, «применить». Курсор над панелью — текстовый.
- [ ] Высота панели 28 / 36 / 44 px; радиус 4 / 8 / 8 px; отступ 2 / 4 / 7 px.
- [ ] Кегль 13 / 14 / 16 px, межстрочный 16 / 20 / 20 px; зазор чипов
      2 / 4 / 8 px.
- [ ] Минимальная ширина поля 360 / 420 / 520 px, панели 369 / 435 / 538 px.
- [ ] Иконки 16 / 20 / 24 px, зазор 8 / 8 / 12 px.
- [ ] Чип «Название: значение», название 500, зазор 2 px; высота 22 / 28 / 28 px;
      отступ 6 / 8 / 8 px; крестик 16 px.
- [ ] Семь типов условий с редакторами по таблице; пустое значение при выходе
      удаляет условие.
- [ ] Цвета чипов, панели и кнопок-иконок — по таблицам.
- [ ] Рамка панели в фокусе `#5D9AF4`; hover панель не меняет; disabled и
      «только чтение» не перекрашивают, курсор — стрелка.
- [ ] Список фильтров: на 5 px ниже поля, не ближе 8 px к краю экрана, ширина
      360–520 px, фильтрация без задержки; строка маски внизу с лупой.
- [ ] Клавиши поля и чипов — по таблицам; чип с фокусом прокручивается в видимую
      область.
- [ ] Индикатора загрузки нет; цвета валидации на чипы не переходят.
