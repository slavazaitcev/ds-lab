## Назначение

Круговой индикатор загрузки. Два режима:

| Режим | Как выглядит |
|---|---|
| Неопределённый | вращающиеся дуги |
| Определённый (с процентом) | дуга заполняется по проценту |

Этот же индикатор стоит внутри кнопки, тега, выбора из списка, автодополнения,
[TagInput](tag-input.md) и [Lightbox](lightbox.md).

## Состав

1. **Квадратный блок** — без фона, рамки и тени.
2. **Кольцо** — незамкнутое, концы штриха круглые, без заливки.
   - В неопределённом режиме — две дуги примерно по 90°, напротив друг друга.
     В начале штрих начинается от «12 часов» по часовой стрелке.
   - Внешний край кольца — 76 % размера блока, внутренний — 52 %.
   - Толщина штриха — 12 % размера блока (около 2,4 px при 20 px).
3. **Фоновая дорожка** — полный неподвижный круг той же толщины. Необязательная.

С `thin` штрих вдвое тоньше: 6 % размера блока (около 1,2 px при 20 px), внешний
край — 70 % размера.

## Свойства

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `size` | `xxs`, `xs`, `sm`, `m`, `lg`, `xl` или число в px | `m` | размер блока |
| `variant` | `primary`, `secondary`, `success`, `danger`, `warning`, `info`, `light`, `dark`, `link`, `body`, `muted`, `black`, `white` | нет | цвет кольца и дорожки |
| `percent` | целое 0–100 | нет | определённый режим |
| `percentNoRotation` | вкл, выкл | выкл | в определённом режиме кольцо не вращается |
| `withBackRotation` | вкл, выкл | выкл | вращение против часовой стрелки |
| `thin` | вкл, выкл | выкл | штрих вдвое тоньше |
| `withBackground` | вкл, выкл | выкл | фоновая дорожка |
| `withTooltip`, `tooltip` | текст, настройки | выкл | подсказка при наведении и фокусе |

## Размеры

Шкала шире общей шкалы контролов.

| Размер | Размер блока |
|---|---|
| `xxs` | 16 px |
| `xs` | 16 px |
| `sm` | 16 px |
| `m` (по умолчанию) | 20 px |
| `lg` | 20 px |
| `xl` | 24 px |

Размер числом — ширина и высота блока в px.

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| Неопределённый режим | две дуги вращаются по часовой, один оборот за 0,667 с |
| Определённый режим | дуга от «12 часов» по часовой; длина дуги = процент × 3,6°; кольцо вращается, один оборот за 2 с |
| 0 % | штриха нет |
| 100 % | почти полное кольцо (около 358°) |
| Больше 100 % | полное кольцо |
| `percentNoRotation` | в определённом режиме кольцо стоит; на неопределённый режим не влияет |
| С дорожкой | дорожка видна всегда; непрозрачность 25 %, при цветном `variant` — 20 % |

Hover, фокуса, disabled, ошибки нет. Состояния окружения не переходят. Курсор
обычный.

текста кнопки.

## Поведение

- Вращение равномерное и непрерывное.
- Длина дуги в определённом режиме меняется сразу, без анимации.
- С `withBackRotation` вращение идёт против часовой стрелки; вид тот же.
- Системная настройка «уменьшить движение» на вращение не влияет.
- Встроенные индикаторы в других виджетах вращаются с той же скоростью.
  Размер задаёт виджет: в кнопке `sm` — 18 px, `m` — 20 px, `lg` — 22 px;
  в выборе из списка — как у лоадера той же ступени (`sm` — 16 px, `m` и `lg` —
  20 px); в [TagInput](tag-input.md) — 18 px, в теге и автодополнении — 20 px,
  в [Lightbox](lightbox.md) — 24 px.

## Клавиатура и скринридер

- Индикатор не получает фокус.
- Определённый режим объявляется как индикатор прогресса со значением от 0 до
  100; процент озвучивается.
- Неопределённый режим ничего не объявляет.
- Подсказка — при наведении и фокусе, см. [Tooltip](tooltip.md).

## Граничные случаи

- Блок фиксированного размера, не растягивается.

## Не определено

Нет.

## Критерии соответствия

- [ ] Квадратный блок 16 / 16 / 16 / 20 / 20 / 24 px (`xxs` … `xl`), `m` по
      умолчанию; размер числом — в px.
- [ ] Две дуги около 90° напротив друг друга, круглые концы; толщина 12 %
      размера; внешний край 76 %; `thin` — вдвое тоньше.
- [ ] Неопределённый режим: оборот 0,667 с по часовой.
- [ ] Определённый режим: дуга от «12 часов», процент × 3,6°; оборот 2 с;
      `percentNoRotation` останавливает.
- [ ] Дорожка — полный неподвижный круг; 25 %, при `variant` — 20 %.
- [ ] Цвета по таблице; по умолчанию `#79818B`.
- [ ] `withBackRotation` — против часовой.
- [ ] Определённый режим озвучивает процент.
