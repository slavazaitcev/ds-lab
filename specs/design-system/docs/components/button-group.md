## Назначение

Группа кнопок-сегментов, которая работает как один контрол выбора. В режиме
`single` выбран один элемент, в режиме `multi` — несколько. Четыре вида: группа
кнопок, группа в коробке, подчёркнутые вкладки, вкладки-закладки.

Замена устаревших виджетов:

| Устаревший | Замена |
|---|---|
| `ButtonGroupChecks` | `ButtonGroup` с `mode="multi"` |
| `ButtonGroupRadios` | `ButtonGroup` с `mode="single"` |

## Состав

1. **Подпись** `Label` сверху. Необязательная. См. [Form](form.md).
2. **Лента элементов** — элементы стоят вплотную в строку (`horizontal`) или в
   столбец (`vertical`). Каждый элемент — кнопка: метка, иконка, текст, счётчик.
3. **Оболочка группы** — зависит от вида:
   - `btn-group` — нет оболочки, фон прозрачный, рамки нет;
   - `btn-group-box` — серая коробка;
   - `tab-underline` — линия-дорожка;
   - `tab-bookmark` — серая полоса-основание с тенью.
4. **Стрелки прокрутки** — появляются поверх ленты, когда элементы не
   помещаются. См. «Поведение».
5. **Строка статуса** `Feedback` или пояснение `HelperText` снизу.
   Необязательная.

Элемент в состоянии hover, нажато, выбрано или фокус рисуется поверх соседей.
Шва между соседними кнопками нет.

## Свойства

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `variant` | `btn-group`, `btn-group-box`, `tab-underline`, `tab-bookmark` | `btn-group` | вид группы |
| `direction` | `horizontal`, `vertical` | `horizontal` | строка или столбец |
| `mode` | `single`, `multi` | `single` | один или несколько выбранных |
| `size` | `sm`, `m`, `lg` | `m` | размер элементов |
| `entries` | элементы: заголовок, иконка, метка, счётчик | — | состав группы |
| `disabled` | вкл, выкл | выкл | вид как в покое; группа не реагирует |
| `readonly` | вкл, выкл | выкл | вид обычный; группа не реагирует |
| `withoutScroll` | вкл, выкл | выкл | при нехватке места элементы сжимаются вместо прокрутки |
| `withoutScrollButtons` | вкл; или отдельно для левой и правой стрелки | выкл | скрыть одну или обе стрелки прокрутки |
| `scrollButtonDelta` | число; или отдельно для каждой стрелки | 1 | на сколько элементов сдвигается лента за одно нажатие стрелки |
| `aria` | `group`, `nav` | `group` | как скринридер называет группу: группа или навигация |

Элементам группы можно передать общие свойства кнопки (например, загрузку,
`multiline`). Режим `noBootstrap` — как у [Button](button.md).

## Состояния

Общее для всех видов:

| Состояние | Что видит пользователь |
|---|---|
| Hover | фон или текст элемента меняется по таблицам «Цвета» |
| Нажато | фон или текст элемента меняется по таблицам «Цвета» |
| Выбрано | элемент в выбранном виде; держится, пока элемент выбран |
| Фокус с клавиатуры | контур 4 px; в прокручиваемой группе — 2 px внутрь; при клике мышью контура нет |
| Disabled | вид как в покое; курсор стандартный; нет hover, нажатия и контура фокуса; нажатия и клавиши не работают |
| Только чтение | вид обычный; нет hover и нажатия; нажатия не работают |
| Загрузка элемента | как у `Button`: содержимое скрыто, по центру индикатор цвета текста; размер сохранён |

Курсор элементов стандартный, у стрелок прокрутки — рука.

## Поведение

### Выбор

- Выбор применяется сразу, без подтверждения.
- `single`: нажатие выбирает элемент. Повторное нажатие на выбранный элемент
  снимает выбор. Группа может остаться без выбора.
- `multi`: каждое нажатие включает или выключает элемент. Несколько выбранных
  подряд просто выглядят выбранными. В `tab-underline` каждая выбранная вкладка
  подчёркнута отдельно.

### Направление

- `horizontal`: элементы в строку, растягиваются и делят свободное место.
- `vertical`: столбец на всю ширину, каждый элемент на всю ширину,
  выравнивание по началу. В `tab-underline` линия-дорожка становится вертикальной
  линией слева, у выбранной вкладки — полоса 2 px слева.

### Прокрутка

Прокрутка включена по умолчанию и работает, когда элементы не помещаются.

- Лента прокручивается вбок (`horizontal`) или вверх-вниз (`vertical`). Полоса
  прокрутки не видна.
- Стрелки появляются только с той стороны, где есть скрытые элементы. На краю
  ленты стрелка исчезает.
- Стрелка — полоса во всю высоту ленты (горизонтально) или во всю ширину
  (вертикально, сверху и снизу). Шеврон повёрнут по направлению.
- При hover шеврон увеличивается на 20 % сразу, без анимации.
- Нажатие на стрелку сдвигает ленту на `scrollButtonDelta` элементов.
- Колесо мыши над горизонтальной группой прокручивает её вбок.
- Нажатие на частично скрытый элемент подтягивает его в видимую область.
- Сдвиг ленты до 50 px — мгновенный, больше — плавный.
- С `withoutScroll` элементы делят ширину ленты и сжимаются; текст обрезается
  многоточием; стрелок нет.

### «Ушки» в `tab-bookmark`

- У невыбранных соседей выбранной вкладки появляется изогнутый клин шириной
  8 px во всю высоту, цвета выбранной вкладки. Вкладка визуально сливается с
  основанием.
- При серии выбранных вкладок ушки есть только у крайних соседей серии.
- Ушки появляются за 0,15 с `ease-in-out`, без задержки.
- Ушки исчезают за 0,15 с `ease-in-out`. Когда вкладка с ушком сама становится
  выбранной или получает фокус, скрытие начинается с задержкой 0,15 с.
- Когда фокус стоит на элементе с ушком, ушко скрыто.
- В вертикальной группе ушек нет.

### Анимация

Цвет, фон и рамка элементов меняются за 0,15 с `ease-in-out`.

## Клавиатура и скринридер

| Клавиша | Действие |
|---|---|
| Tab | переход к следующему элементу; disabled-элементы пропускаются |
| Enter | нажатие на элемент |
| Space | нажатие на элемент |
| Стрелки | ничего не делают |

- Скринридер называет группу «группой» или «навигацией» (`aria`) и сообщает
  направление.
- Каждый элемент объявляется кнопкой; имя — заголовок элемента.
- Выбранный элемент объявляется выбранным.
- Состояния disabled и «только чтение» объявляются для всей группы.

## Граничные случаи

- Узкий контейнер: длинная группа прокручивается. С `withoutScroll` элементы
  сжимаются, текст обрезается многоточием.
- Длинная подпись обрезается многоточием; с `multiline` переносится.
- Большое число в счётчике расширяет таблетку.
- Вертикальная группа, которая не помещается по высоте, прокручивается со
  стрелками сверху и снизу.

## Не определено

Нет.

## Критерии соответствия

- [ ] Четыре вида: `btn-group`, `btn-group-box`, `tab-underline`,
      `tab-bookmark`.
- [ ] По умолчанию: `variant` — `btn-group`, `direction` — `horizontal`,
      `mode` — `single`, `aria` — `group`, `scrollButtonDelta` — 1, `size` — `m`.
- [ ] Элементы стоят вплотную без зазоров; активный элемент поверх соседей;
      полоса прокрутки не видна.
- [ ] Стрелки прокрутки: ширина полосы 32 / 36 / 40 px, шеврон `#5D9AF4`,
      градиент-затухание; шеврон увеличивается на 20 % при hover; стрелка только
      со стороны скрытых элементов.
- [ ] Контур фокуса только с клавиатуры: 4 px, Light `#BED6FB`, Dark `#5D9AF4`
      (в `tab-underline` — Dark `#6DA4F5`);
      в прокрутке — 2 px внутрь; в disabled контура нет.
- [ ] `single`: повторное нажатие снимает выбор. `multi`: элементы переключаются
      независимо.
- [ ] `btn-group-box`: коробка с отступом 2 px, радиус 6 / 8 / 8 px, фон
      `#ECEDEF` / `#1C283A`; выбранный элемент `#FFFFFF` / `#2A384F`.
- [ ] `tab-underline`: линия 1 px `#ECEDEF` / `#2A384F`, зазор 16 / 20 / 24 px,
      высота вкладки 34 / 38 / 38 px, полоса выбранной 2 px `#5D9AF4` /
      `#6DA4F5`; в вертикальной группе линия и полоса слева.
- [ ] `tab-bookmark`: основание `#DEE0E3` / `#212E41`, три тени вверх, выбранная
      вкладка `#FFFFFF` / `#2A384F`, ушки 8 px у крайних соседей, скрыты при
      фокусе.
- [ ] Цвет, фон и рамка меняются за 0,15 с `ease-in-out`.
- [ ] Disabled: вид как в покое, нет hover, нажатия и контура. «Только чтение»:
      вид обычный, нажатия не работают. Загрузка: индикатор 18 / 20 / 22 px.
