## Назначение

Модальное окно: содержимое по центру экрана поверх затемнения. Пока окно
открыто, фокус остаётся внутри него.

`Modal` задаёт только положение окна, затемнение, удержание фокуса и скрытую
кнопку закрытия. Само окно (фон, шапку, тело, подвал) задаёт приложение.

`MaybeModal` — то же с выключателем `withoutModal`. Когда выключатель включён,
содержимое стоит на своём месте в странице, без затемнения и без поведения окна.

На основе `Modal` построена галерея [Lightbox](lightbox.md).

## Состав

1. **Затемнение** — на весь экран.
2. **Окно** — по центру экрана по горизонтали и вертикали. Размер — по
   содержимому.
3. **Скрытая кнопка закрытия** — для скринридера; визуально не видна (1 × 1 px).
   Текст «Dismiss» (можно заменить).

У самого `Modal` у окна нет фона, рамки, тени, радиуса и своего курсора.
Типографику окна задаёт его содержимое.

## Свойства

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| Показ (`isShow`) | вкл, выкл | выкл | окно открыто или закрыто; открывает и закрывает приложение |
| `withoutBackdrop` | вкл, выкл | выкл | без затемнения |
| `closeOnEscape` | вкл, выкл | выкл | закрытие по Escape |
| `closeOnBackdrop` | вкл, выкл | выкл | закрытие по клику вне окна |
| `lockBodyScroll` | вкл, выкл | выкл | страница под окном не прокручивается |
| `withFocusManager` | вкл, выкл | вкл | фокус переходит в окно, остаётся в нём и возвращается после закрытия |
| Скрытая кнопка закрытия | вкл, выкл, свой текст | вкл, «Dismiss» | кнопка для скринридера |
| `disableAllFeatures` | вкл, выкл | выкл | выключить поведение окна: нет затемнения, Escape и клик вне не закрывают |
| `withoutModal` (`MaybeModal`) | вкл, выкл | выкл | содержимое на своём месте в странице, без поведения окна |

Размеров `sm`, `m`, `lg` нет.

## Размеры

| Метрика | Значение |
|---|---|
| Затемнение | весь экран |
| Окно | по содержимому; по центру экрана |
| Уровень слоя окна и затемнения | 1050 |
| Скрытая кнопка | 1 × 1 px |

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| Закрыто | окна и затемнения нет |
| Открыто | окно по центру, затемнение под ним |
| Без затемнения | только окно |
| Поведение окна выключено | нет затемнения, окно не закрывается по Escape и клику вне |

Hover, фокус, disabled, загрузка и ошибка — состояния содержимого окна, не
`Modal`.

## Поведение

### Открытие

- Окно открывает приложение. Своей кнопки-триггера у `Modal` нет.
- Окно появляется сразу, без анимации.

### Закрытие

| Способ | Когда работает |
|---|---|
| Escape | если включено `closeOnEscape` |
| Клик вне окна (по затемнению или по странице) | если включено `closeOnBackdrop`; нажатие и отпускание должны быть вне окна; мышь и касание |
| Скрытая кнопка закрытия | всегда, если кнопка включена |
| Действие приложения | всегда |

Окно исчезает сразу, без анимации. Фокус возвращается к элементу, который открыл
окно.

### Несколько окон

Окна стоят стопкой. Escape и клик вне закрывают только верхнее окно.

### Прокрутка

- С `lockBodyScroll` страница не прокручивается, пока окно открыто. После
  закрытия прокрутка возвращается как была.
- Своей прокрутки у окна нет. Если содержимое выше экрана, окно выходит за край
  экрана.

### Вложенные оверлеи

Поповеры и меню внутри окна работают как обычно. Порядок слоёв — см.
[Слои](../foundations/layering.md).

## Клавиатура и скринридер

| Клавиша | Действие |
|---|---|
| Escape | закрыть (если включено `closeOnEscape`); пока окно открыто, Escape не доходит до остальной страницы, даже если закрытие по Escape выключено |
| Tab, Shift+Tab | переход только внутри окна |

- При открытии фокус встаёт на первый интерактивный элемент внутри окна. Если
  внутри окна нет интерактивных элементов, фокус встаёт на само окно. Фокус
  остаётся внутри: Tab и Shift+Tab переводят его по интерактивным элементам окна
  по кругу. При закрытии фокус возвращается к элементу, который открыл окно.
- Уход фокуса наружу окно не закрывает.
- Окно объявляется диалогом.
- Скрытая кнопка «Dismiss» не входит в порядок Tab. Это выход для скринридера.

## Граничные случаи

- На узких и низких экранах окно всё равно по центру; ограничений размера нет.
- Единственный текст виджета — «Dismiss»; его можно заменить.

## Не определено

Нет.

## Критерии соответствия

- [ ] Окно по центру экрана, размер по содержимому; своего фона, рамки, тени и
      радиуса у `Modal` нет.
- [ ] Затемнение на весь экран, `#01070E` с непрозрачностью 70 %, одинаково во
      всех темах; уровень 1050.
- [ ] Появление и закрытие мгновенные.
- [ ] Escape закрывает только при `closeOnEscape`, клик вне — только при
      `closeOnBackdrop`; по умолчанию оба выключены.
- [ ] После закрытия фокус возвращается к элементу, который открыл окно.
- [ ] При открытии фокус встаёт на первый интерактивный элемент окна; если их
      нет — на само окно; Tab ходит по элементам окна по кругу.
- [ ] С `lockBodyScroll` страница не прокручивается; после закрытия прокрутка
      как была.
- [ ] Внутреннего скролла у окна нет; если содержимое выше экрана, окно выходит
      за край экрана.
- [ ] Скрытая кнопка «Dismiss» включена по умолчанию, не видна, не входит в Tab.
- [ ] Несколько окон: закрывается только верхнее.
- [ ] `withoutModal` и `disableAllFeatures`: содержимое на месте, без затемнения
      и без закрытия.
