## Назначение

Грань — видимая часть закрытого [Selector](selector.md): поле, кнопка или чип.
По нажатию на грань открывается панель [SelectorDropdown](selector-dropdown.md).

| Грань | Режим | Вид |
|---|---|---|
| `SelectorReferenceSingleInput` | один | поле |
| `SelectorReferenceMultiInput` | несколько | поле со сводкой в одну строку |
| `SelectorReferenceMultiTagsInput` | несколько | поле с чипами внутри |
| `SelectorReferenceSingleButton` | один | кнопка |
| `SelectorReferenceMultiButton` | несколько | кнопка со сводкой |
| `SelectorReferenceSingleTag` | один | чип |
| `SelectorReferenceMultiTag` | несколько | чип со сводкой |
| `SelectorReferenceMultiTagWithCounter` | несколько | чип с первыми значениями и счётчиком |

## Состав

Части:

1. **Ведущий элемент** — ровно один: иконка, метка, изображение или произвольное
   содержимое. Необязательный.
2. **Значение** — или текст пустого состояния «Не выбрано».
3. **Шеврон** — у поля и кнопки; у чипа шеврона нет.
4. **Индикатор загрузки** — вместо содержимого во время загрузки.

Несколько значений в одной строке показываются так:

- через «, »;
- или «Выбрано N» (с правильным склонением: «Выбрано 1 значение», «Выбрано 2
  значения», «Выбрано 5 значений»).

Виды граней:

| Грань | Как выглядит |
|---|---|
| Поле, один выбор | как текстовое поле: значение или «Не выбрано», ведущий элемент, шеврон; открытая грань — рамка цвета акцента. Вводить текст можно только при поиске в грани (`filterPlacement="reference"`) |
| Поле, несколько, чипы (по умолчанию) | поле растёт вниз, чипы переносятся; у каждого выбранного значения — чип [Tag](tag.md) с крестиком (крестик снимает выбор); между чипами — поле поиска шириной от 60 px |
| Поле, несколько, сводка | когда выбрано больше порога: одна строка «, » или «Выбрано N»; поле работает как поиск |
| Кнопка, один выбор | кнопка [Button](button.md) размера грани; значение по центру в одну строку; пока панель открыта, кнопка выглядит нажатой |
| Кнопка, несколько | та же кнопка с переносом текста; значения в виде сводки на несколько строк |
| Чип, один выбор | чип [Tag](tag.md) размера грани; при открытии — вид «выбран»; крестика нет |
| Чип, несколько | один чип со всеми значениями через «, »; при превышении порога — первые N значений и счётчик «+остаток»; крестика нет |

## Свойства

Общие свойства выбора — в [Selector](selector.md). Варианты `buttonVariant` у
грани-кнопки:

| `buttonVariant` | Варианты кнопки по статусу |
|---|---|
| `outlined` | `outline-primary`, `outline-success`, `outline-warning`, `outline-danger` |
| `filled` | `primary`, `success`, `warning`, `danger` |
| `text` | `text-primary`, `text-success`, `text-warning`, `text-danger` |
| `none` | без оформления |

Шрифт поля — Roboto 400; у кнопки — как у [Button](button.md); у чипа — как у
[Tag](tag.md).

| Шеврон | 20 px | 20 px | 20 px |
| Шеврон: ширина слота | 20 px | 24 px | 24 px |
| Индикатор загрузки | 16 px | 20 px | 20 px |

отступ.

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| Покой | рамка цвета фона, фон залит, курсор — рука (над текстом — текстовый) |
| Hover | грань не меняется |
| Фокус или панель открыта | рамка 1 px `#5D9AF4`; тени нет; плейсхолдер поля светлеет |
| Disabled | курсор — стрелка; клики и клавиши не работают; рамка, фон и текст обычные (не тускнеет); шеврон, чипы и крестики не реагируют; поле теряет фокус |
| Только чтение | вид как в покое; крестики чипов и поиск не работают; кнопка — в виде «только чтение» |
| Ошибка, предупреждение, успех | рамка цвета состояния, фон — бледный оттенок; в фокусе рамка цветная, фон обычный |
| Загрузка | вместо содержимого — индикатор; плейсхолдер скрыт |
| Пусто | «Не выбрано» или свой вид |
| Выбрано несколько | чипы с крестиками, сводка «, », «Выбрано N» или «+остаток» |

Чипы в поле — инвертированный вид [Tag](tag.md): `#FFFFFF` в Light, `#2A384F` в
Dark. Когда грань в фокусе, чипы выглядят обычно. Крестик чипа — `ti ti-x`.

## Поведение

Рамка и фон грани меняются за 150 мс `ease-in-out`. Цвет текста и иконок —
мгновенно. При системной настройке «уменьшить движение» — мгновенно.

## Клавиатура и скринридер

Клавиши грани — в [Selector](selector.md).

## Граничные случаи

- Поле с чипами растёт вниз; шеврон остаётся в первом ряду, поле оставляет под
  него место.
- Сводка «, » обрезается многоточием.

## Не определено

Нет.

## Критерии соответствия

- [ ] Грань: отступы 9 / 11 / 11 px и 7 / 7 / 9 px, кегль 13 / 14 / 14 px, радиус
      6 / 8 / 8 px, рамка 1 px; шеврон 20 px в слоте 20 / 24 / 24 px; индикатор
      16 / 20 / 20 px.
- [ ] Фон грани `#ECEDEF` / `#1E2B3E`; при открытии рамка `#5D9AF4`; hover грань
      не меняет.
- [ ] Поле с чипами: чипы 24 / 28 / 28 px, зазор 4 px, поле поиска от 60 px;
      сводка «, », «Выбрано N» или «+остаток» по порогам.
- [ ] Переход рамки и фона грани 150 мс.
