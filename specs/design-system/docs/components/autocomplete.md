## Назначение

Подсказки к текстовому полю. Пока пользователь печатает, рядом с полем или с
курсором появляется панель с вариантами. Выбор варианта вставляет его текст в
поле. Выбирать не обязательно: можно ввести своё значение.

Сам виджет поля не рисует. Он работает с любым полем: однострочным,
многострочным, редактируемым текстом. [TagFilter](tag-filter.md) использует его
для списка фильтров.

`MaybeAutocomplete` — то же самое с выключателем `withoutAutocomplete`. Когда
выключатель включён, подсказок нет, поле работает как обычно.

## Состав

### Панель: состав

- Прямоугольная всплывающая панель.
- Без стрелки, без затемнения, без анимации.
- Внутри только список строк или заглушка. Шапки и подвала нет.
- Курсор над строкой — рука.

### Строка варианта

Слева направо:

1. **Ведущие элементы:** элементы из списка `elements`, затем иконка, затем
   метка, затем аватар. Необязательные.
2. **Основной текст** — растягивается, переносится.
3. **Вторичный текст** — справа, по правому краю, шириной 50 % строки; или сразу
   после основного текста, тем же кеглем. Необязательный.

Сверху и снизу у строки может быть разделитель 1 px. У строки может быть
подсказка [Tooltip](tooltip.md): показывается при наведении и фокусе.

### Заглушки

| Заглушка | Что внутри |
|---|---|
| Загрузка | строка с индикатором [Loader](loader.md) по центру, цвет `#79818B` |
| Пусто | приглушённый текст по центру «Подходящие значения отсутствуют»; только если включено `showEmptyList` |
| Ошибка | текст ошибки по центру (по умолчанию «Не удалось загрузить список»; можно «заголовок: описание»); под ним кнопка «Повторить» (`text-primary`) на всю ширину, высотой строки; нажатие загружает список заново |

## Свойства

| Свойство | Значения | По умолчанию | Что меняется |
|---|---|---|---|
| `size` | `sm`, `m`, `lg` | `m` | размеры строк и панели |
| `activation` | `fulltext`, `word`, `custom` | `fulltext` | когда появляется панель, см. «Поведение» |
| Минимальная длина | число символов | 0 | панель появляется, когда текста не меньше |
| Триггер (`word`) | символ или список: например `@`, `#`, `/` | нет | панель только для слова, которое начинается с триггера |
| `anchor` | `reference`, `cursor` | `reference` | панель под полем или у курсора |
| `minWidthPx` | px | по размеру | минимальная ширина панели |
| `showEmptyList` | вкл, выкл | выкл | показывать заглушку «пусто» |
| `showSingleMatchList` | вкл, выкл | выкл | показывать панель, когда есть единственный точный вариант |
| `lang` | русский, английский, французский | русский | тексты заглушек |
| `withoutAutocomplete` (`MaybeAutocomplete`) | вкл, выкл | выкл | подсказки выключены |

Для строки:

| Свойство | Значения | Что меняется |
|---|---|---|
| `withDividerAbove` | вкл, выкл | линия 1 px сверху |
| `withDividerBelow` | вкл, выкл | линия 1 px снизу |
| `withTooltip` | текст | подсказка строки |

## Размеры

Шрифт Roboto, начертание 400, межбуквенный интервал 0.

| Строка: отступ слева и справа | 8 px | 12 px | 12 px |

| Вторичный текст: межстрочный | 14 px | 16 px | 20 px |

Высота строки = 2 × отступ сверху и снизу + межстрочный основного текста. Предел
высоты панели отсчитывается от высоты строки 32 / 36 / 40 px: на `sm` панель
вмещает до 9 строк, на `m` — 8, на `lg` — 7.

Одинаково на всех размерах:

| Метрика | Значение |
|---|---|
| Радиус панели | 8 px |
| Рамка панели | 1 px |
| Тень панели | смещение по Y 2 px, размытие 8 px |
| Зазор полосы прокрутки | 4 px |
| Контур фокуса «Повторить» | внутрь на 4 px |

## Состояния

### Строка

| Состояние | Что видит пользователь |
|---|---|
| Покой | фон панели |
| Hover или выбрана с клавиатуры | одна и та же серая заливка; на сенсорных экранах — так же |

Своих фокуса, нажатия и disabled у строки нет. Подсветка с клавиатуры —
виртуальная: фокус остаётся в поле. Клик выбирает строку.

### Панель: состояния

| Ситуация | Что видит пользователь |
|---|---|
| Есть варианты | панель видна |
| Нет вариантов, `showEmptyList` выкл | панели нет; стрелки не работают |
| Нет вариантов, `showEmptyList` вкл | заглушка «пусто» |
| Единственный точный вариант, `showSingleMatchList` выкл | панели нет; стрелки не работают |
| Загрузка | заглушка загрузки |
| Ошибка | текст ошибки и «Повторить» |

Своих disabled, «только чтение», обязательности и ошибки у виджета нет. Это
состояния поля. Если поле недоступно, курсора в нём нет, и панель не
появляется.

Закрытие сильнее подсветки: Enter, клик, Escape и уход фокуса срабатывают, даже
если строка подсвечена.

## Поведение

### Когда появляется панель

| `activation` | Когда | Что ищется |
|---|---|---|
| `fulltext` | в поле есть курсор и длина текста не меньше минимальной | весь текст от начала до курсора |
| `word` | курсор внутри слова; если задан триггер — только в слове, которое начинается с триггера; минимальная длина считается без триггера | текущее слово вместе с триггером |
| `custom` | когда это решает правило приложения | то, что вернуло правило |

Разделители слов для `word`: `. , ; ! ? ( ) [ ] { } " ' « » ‹ › „ ‚` и все
пробельные символы. Часть разделителей можно отключить.

Если курсора в поле нет (фокус вне поля или выделен текст), панели нет.

Панель реагирует на ввод не чаще раза в 100 мс; список фильтруется через 150 мс
после ввода.

### Фильтр

Вариант остаётся, если его текст начинается с введённой строки. Регистр не
важен, пробелы по краям не учитываются. Пустая строка — показываются все
варианты. Совпавшая часть не подсвечивается.

### Где появляется панель

| `anchor` | Положение |
|---|---|
| `reference` | под полем, левый край по полю, без зазора; если внизу нет места — над полем |
| `cursor` | у первого символа текущего слова: ниже на половину высоты символа и левее на половину ширины символа (при пустом тексте — без сдвига); если внизу нет места — выше |

- Ширина — ширина поля, но не меньше минимальной.
- Высота — оставшееся место на экране, но не больше 256 / 288 / 320 px (для `sm` /
  `m` / `lg`). Дальше — прокрутка внутри панели с тонкой полосой.
- Появляется и исчезает мгновенно.

### Выбор

| `activation` | Что вставляется |
|---|---|
| `fulltext` | текст от начала поля до курсора заменяется выбранным значением |
| `word`, `custom` | заменяется только текущее слово; после него добавляется один пробел |

После вставки курсор стоит сразу после вставленного текста (для `word` — после
пробела). Фокус остаётся в поле. Панель закрывается.

### Закрытие

- Escape — текст не меняется.
- Выбор варианта.
- Уход фокуса из поля. Переход фокуса внутрь панели панель не закрывает.
- Выделение текста в поле.

При повторном срабатывании условия список просто перефильтровывается.

### Загрузка

Варианты подгружаются порциями по мере прокрутки.

### Тексты

| Текст | ru | en | fr |
|---|---|---|---|
| Пусто | Подходящие значения отсутствуют | No matching options | Aucune option correspondante |
| Ошибка | Не удалось загрузить список | Failed to load list of options | Impossible de charger la liste des options |
| Повторить | Повторить | Retry | Réessayer |

Автозаполнение браузера для поля отключается.

## Клавиатура и скринридер

Фокус всегда в поле. Подсветка строки виртуальная: скринридер объявляет активную
строку, но фокус не переносится. Панель объявляется списком, строки — пунктами
списка.

| Клавиша | Действие |
|---|---|
| ↓ | первый раз — первая строка, дальше — следующая; с последней на первую не переходит |
| ↑ | предыдущая строка; с первой на последнюю не переходит |
| Home | первая строка |
| End | последняя строка |
| Enter | если строка подсвечена — выбрать; если нет — обычное действие поля |
| Escape | закрыть панель |

- Наведение мыши подсвечивает строку той же заливкой. Клик выбирает.
- Клавиши перехватываются только при открытой панели: ↓, ↑, Home, End, Enter.
- «Повторить» — обычная кнопка.
- Анимаций нет; настройка «уменьшить движение» на виджет не влияет.

## Граничные случаи

- На узком экране панель сжимается до свободного места и при нехватке места
  открывается вверх.
- Длинные значения переносятся. Вторичный текст занимает до 50 % ширины и тоже
  переносится.
- Строка с длинным текстом растёт по высоте (не ниже высоты строки); панель
  прокручивается.

## Не определено

Нет.

## Критерии соответствия

- [ ] Панель без стрелки и затемнения, появляется и исчезает мгновенно.
- [ ] Радиус 8 px, рамка 1 px, тень смещение 2 px и размытие 8 px; цвета по
      таблице.
- [ ] `reference` — под полем без зазора, левый край по полю; `cursor` — у начала
      слова со сдвигом на половину символа; при нехватке места — вверх.
- [ ] Ширина — по полю, не меньше 360 / 420 / 520 px; высота не больше
      256 / 288 / 320 px, дальше прокрутка.
- [ ] Строка: элементы, затем текст, зазор 8 px; высота 28 / 36 / 44 px;
      вторичный текст справа до 50 % или сразу после основного; разделители 1 px.
- [ ] Заглушки: индикатор 16 / 20 / 24 px; «Подходящие значения отсутствуют»
      только при `showEmptyList`; ошибка «Impossible de charger la liste des
      options» (fr) с «Повторить».
- [ ] Фильтр по началу текста, без учёта регистра; совпадение не подсвечивается.
- [ ] Три способа появления (`fulltext`, `word`, `custom`); без курсора, без
      вариантов и при единственном точном варианте панели нет (если не включены
      соответствующие свойства).
- [ ] Вставка: `fulltext` заменяет текст до курсора; `word` и `custom` — только
      слово и добавляют пробел; фокус остаётся в поле.
- [ ] Клавиши ↓, ↑ без перехода по кругу, Home, End, Enter, Escape; hover и
      клавиатура подсвечивают одинаково.
- [ ] Реакция на ввод не чаще 100 мс, фильтр через 150 мс; закрытие по Escape,
      выбору, уходу фокуса.
