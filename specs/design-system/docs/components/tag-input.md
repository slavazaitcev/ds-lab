## Назначение

Поле ввода, которое превращает введённый текст в чипы. Пользователь набирает
текст, и он становится удаляемым чипом. Чипы можно удалять, очищать все сразу и
менять местами.

## Состав

Сверху вниз:

1. **Подпись** — необязательная. См. [Form](form.md).
2. **Поле.**
3. **Строка статуса или пояснение** — необязательные. См. [Form](form.md).

Внутри поля — полоса содержимого слева и колонка с крестиком «очистить всё»
справа. Содержимое выровнено по центру по вертикали.

Части полосы слева направо:

1. **Чипы** — в порядке списка. Это `Tag` в инвертированном виде (см. «Цвета»).
   Чипы не кликабельны и не меняются при hover. У чипа работает только крестик
   удаления.
2. **Индикатор проверки** — во время проверки нового значения. Необязательный.
3. **Поле набора** — одна строка, без рамки, прозрачное. Курсор текстовый.
   Плейсхолдер обрезается многоточием.

**Крестик «очистить всё»** — справа, на уровне первой строки, немного заходит на
внутренний край полосы. Необязательный. Курсор — рука. Зазор между полосой и
крестиком — 4 px.

## Состояния

### Поле

| Состояние | Что видит пользователь |
|---|---|
| Покой | серый фон и рамка того же цвета |
| Hover | ничего не меняется |
| Фокус | меняется только цвет рамки; плейсхолдер светлеет; контура нет |
| Валидация | цветной фон и цветная рамка |
| Валидация + фокус | рамка цветная, фон обычный; цвета валидации у чипов снимаются |
| Проверка значения | набранный текст скрыт, виден индикатор проверки |
| Disabled | всё поле с непрозрачностью 60 %; курсор — стрелка; hover и фокус не работают; поле набора скрыто даже без чипов; крестик «очистить всё» не реагирует |
| Только чтение | вид как в покое; ничего не работает; поле набора скрыто |

Disabled сильнее hover и фокуса.

## Поведение

### Как набранный текст становится чипом

| Действие | Результат |
|---|---|
| Enter | весь набранный текст (без пробелов по краям) становится одним чипом; пустой текст ничего не создаёт |
| Набран разделитель (`separator`) | текст до разделителя сразу становится чипом, остаток остаётся в поле набора; несколько разделителей подряд и пустые фрагменты чипов не создают |
| Вставка с `addOnPaste` | текст разбивается на чипы по разделителям; остаток после последнего разделителя остаётся в поле набора; без разделителя вся строка — один чип |
| Вставка без `addOnPaste` | текст вставляется обычно, но разделители всё равно разбивают его |
| Уход фокуса с `addOnBlur` | набранный текст становится чипом; разделители разбивают как при Enter |

### Повторы

- По умолчанию (`distinct` вкл) значение, равное существующему чипу, не
  добавляется. Повторы внутри одной вставки тоже отбрасываются.
- С `distinct` выкл повторы становятся отдельными чипами.

### Проверка значения (`canAddTag`)

- Отклонённое значение чипом не становится.
- Если из нескольких значений прошло хотя бы одно, отклонённые просто
  отбрасываются.
- Если отклонены все, текст остаётся в поле набора.
- Если проверка длится дольше 100 мс, набранный текст скрывается и появляется
  индикатор. Когда проверка закончена, появляются чипы, и фокус возвращается в
  поле набора.

### Удаление и очистка

- Крестик на чипе удаляет этот чип.
- Delete или Backspace на выбранном чипе удаляет его.
- Крестик «очистить всё» удаляет все чипы.

### Перетаскивание (`withReorder`)

- Чип перетаскивается указателем или с клавиатуры: выбранный чип поднимается
  пробелом или Enter, перемещается стрелками, опускается пробелом, Enter или
  Tab, Escape отменяет.
- Перетаскиваемый чип выглядит как выбранный, подсказка не показывается,
  курсор — «захват». Подъёма и тени нет.
- Соседи раздвигаются за 0,25 с, кривая `cubic-bezier(0.25, 1, 0.5, 1)`.
- При отпускании порядок фиксируется. Отпускание вне допустимого места отменяет
  перестановку.

### Анимация

- Рамка и фон поля и чипов меняются за 0,15 с `ease-in-out`.
- Индикатор проверки: 0,667 с на оборот; при системной настройке «уменьшить
  движение» — 1,333 с.
- Остальное меняется мгновенно.

### Подсказка

Показывается при наведении и фокусе. Текст — заданный или все значения через
запятую. Вид — как у [Tooltip](tooltip.md).

## Клавиатура и скринридер

Поле — одна остановка Tab. Фокус попадает в поле набора, а если его нет — на
последний чип. В каждый момент выбран либо ввод, либо один чип. Выбранный чип
подсвечен как «выбран».

Когда выбран чип:

| Клавиша | Действие |
|---|---|
| ← | выбрать предыдущий чип; на первом — ничего; при перетаскивании — переместить чип |
| → | выбрать следующий чип; после последнего — фокус в поле набора; при перетаскивании — переместить чип |
| Home | выбрать первый чип |
| End | выбрать последний чип |
| Delete, Backspace | удалить чип; выбрать предыдущий; если удалён первый — выбрать новый первый или перейти в поле набора, если чипов нет |
| Печатный символ | фокус в поле набора |
| Space, Enter | при `withReorder` вкл — поднять выбранный чип; при перетаскивании — опустить; иначе Space — ничего |
| ↑, ↓ | при перетаскивании — переместить чип; иначе — ничего |
| Escape | при перетаскивании — отменить; иначе — ничего |
| Tab, Shift+Tab | выйти из поля |

Когда фокус в поле набора:

| Клавиша | Действие |
|---|---|
| Enter | набранный текст становится чипом |
| ← или Backspace при пустом поле набора | выбрать последний чип |
| →, Home, End | обычное движение по тексту |
| Tab, Shift+Tab | выйти из поля |

- Крестик «очистить всё» не входит в порядок Tab. Он доступен только
  указателем. Скринридер объявляет его кнопкой.
- После удаления последнего чипа и после проверки фокус возвращается в поле
  набора.
- Если поле становится disabled, фокус снимается.
- При уходе фокуса из поля выбор чипа снимается.
- Скринридер объявляет поле списком значений через запятую. Disabled-поле
  объявляется недоступным. Индикатор проверки объявляется как у
  [Loader](loader.md).
- При перетаскивании скринридер объявляет подсказку: пробел поднимает чип,
  стрелки перемещают, пробел или Enter опускает, Escape отменяет; перенос чипа
  объявляется по шагам и в конце.

## Граничные случаи

- В узком контейнере чипы переносятся на новые строки, поле растёт вниз,
  прокрутки нет.
- Длинный чип и длинный плейсхолдер обрезаются многоточием.
- Одиночное поле набора на перенесённой строке стоит примерно на 2 px правее
  чипов следующей строки.
- Если `withAdd` выкл и чипы есть, видны только чипы.

Нет.

## Критерии соответствия

- [ ] Поле: рамка 1 px, радиус 6 / 8 / 8 px, минимальная высота 32 / 36 / 40 px.
- [ ] Отступы поля: 3 и 3 px (`sm`), 3 и 5 px (`m`), 5 и 5 px (`lg`) — сверху-снизу
      и слева-справа.
- [ ] Чипы: высота 22 / 28 / 28 px, кегль 13 / 14 / 16 px, отступ 6 / 8 / 8 px,
      зазор 4 px.
- [ ] Поле набора: кегль 13 / 14 / 14 px, высота 24 / 28 / 28 px, минимальная
      ширина 60 px. Минимальная ширина поля 72 / 76 / 76 px.
- [ ] Крестик «очистить всё» 20 px; индикатор проверки 16 / 18 / 18 px.
- [ ] Порядок: чипы, индикатор, поле набора; крестик «очистить всё» справа на
      уровне первой строки. Поле растёт вниз, прокрутки нет.
- [ ] Hover поля ничего не меняет; фокус меняет только цвет рамки на `#5D9AF4`.
- [ ] Цвета поля и валидации — по таблице. Disabled — 60 %, «только чтение» —
      как покой.
- [ ] Чипы инвертированы; «выбран» — `#EFF5FE` с рамкой `#5D9AF4` (Light); чипы
      не кликабельны; цвета валидации чипов снимаются, когда поле в фокусе.
- [ ] Крестик «очистить всё» не входит в Tab и очищает все чипы.
- [ ] Enter, разделитель, вставка и уход фокуса создают чипы по таблице;
      повторы — по `distinct`.
- [ ] Проверка дольше 100 мс показывает индикатор; если отклонены все значения,
      текст остаётся.
- [ ] Клавиши ←, →, Home, End, Delete, Backspace работают по таблицам; поле —
      одна остановка Tab.
- [ ] Перетаскивание: вид «выбран», соседи раздвигаются за 0,25 с, курсор
      «захват», отмена вне допустимого места; с клавиатуры — пробел поднимает,
      стрелки перемещают, пробел или Enter опускает, Escape отменяет.
