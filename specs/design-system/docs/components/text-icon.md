## Назначение

- `Text` — любой текст. Понимает простую разметку внутри строки: жирный, курсив,
  ссылки, код.
- `Icon` — одна иконка из шрифтового набора.

Оба виджета почти не имеют своего вида: шрифт, размер и цвет берутся из
окружения.

## Состав

### `Text`

- Строчный элемент: стоит в строке, как обычный текст.
- Содержимое — строка с разметкой или произвольное содержимое.
- Своих шрифта, кегля, межстрочного, межбуквенного интервала, отступов, цвета,
  фона, рамки, скругления, тени и курсора нет. Всё берётся из окружения.
- Своей шкалы размеров нет: кегль задаёт окружение (обычно размер виджета).

### `Icon`

- Строчный элемент. Иконка задаётся именем вида `ti ti-sun`, `ti ti-chevron-left`,
  `ti ti-x`.
- Иконку рисует шрифтовой набор Tabler Icons 3.35.0. Иконка — квадрат со
  стороной, равной кеглю.
- Кегль, цвет и межбуквенный интервал — из окружающего текста. Своей настройки
  размера нет.
- Начертание всегда обычное (400). Тонкие начертания 300 и 200 через `Icon`
  недоступны.
- Рядом с текстом иконка стоит на общей базовой линии.
- Внутри виджета иконка стоит в квадратном слоте ровно своего размера, по
  центру; слот выровнен по центру строки.
- Цвет — цвет окружающего текста: в кнопке — цвет текста кнопки, в поле с
  ошибкой — цвет ошибки.

## Свойства

| Свойство | Виджет | Значения | По умолчанию | Что меняется |
|---|---|---|---|---|
| `value` | `Text` | строка с разметкой | — | текст |
| `value` | `Icon` | имя иконки `ti ti-…` | — | иконка |
| `fontWeight` | `Text` | 100, 300, 400, 500, 700, 900 | из окружения | начертание; единственная своя настройка вида у `Text` |
| `size` | оба | `sm`, `m`, `lg` | из окружения | вид не меняет |
| `as` | оба | роль элемента: заголовок, абзац, кнопка и т. п. | обычный строчный элемент | роль для скринридера; вид не меняет |
| `withTooltip`, `tooltip` | оба | выкл, вкл, текст | выкл | подсказка при наведении и фокусе |
| `isInvalid`, `isWarning`, `isValid`, `feedback` | оба | вкл, выкл | выкл | своих цветов нет; цвет задаёт окружение |
| `noBootstrap` | оба | вкл, выкл | выкл | вид не меняется: своего оформления нет |

## Размеры

Своих размеров нет. Размеры иконок в виджетах: `sm` — 16 px, `m` и `lg` — 20 px.
Подробности и зазоры — в [Иконках](../foundations/icons.md).

## Состояния

Своих состояний нет: hover, фокус, нажатие, disabled, «только чтение»,
обязательность и валидация не меняют вид. Вид всегда берётся из окружения.

## Цвета

Своих цветов нет. Цвет — цвет окружающего текста.

## Поведение

### Разметка в `Text`

Работает только в строке `value`, не в произвольном содержимом.

| Как написать | Что видно |
|---|---|
| `**текст**` | жирный |
| `*текст*` | курсив |
| `***текст***` | жирный курсив |
| `~~текст~~` | зачёркнутый |
| `` `текст` `` | строчный код, моноширинный шрифт |
| `[текст](адрес)` | ссылка |
| `[текст](адрес "заголовок")` | ссылка со всплывающим заголовком |
| `&nbsp;` | неразрывный пробел |
| всё остальное | как написано |

Разметку можно вкладывать: например, жирный текст внутри ссылки. Неизвестная
разметка выводится как обычный текст. Имя иконки в `Icon` не размечается.

### Подсказка

- `withTooltip` = вкл — подсказка с содержимым из `tooltip`.
- `withTooltip` = текст — подсказка с этим текстом.
- Показывается при наведении и при фокусе (если элемент получает фокус).
- Закрывается как [Tooltip](tooltip.md): Escape, уход курсора, уход фокуса.

## Клавиатура и скринридер

- Сами по себе `Text` и `Icon` не получают фокус.
- Фокус есть только у нажимаемых элементов: например, у ссылки в разметке или
  у иконочной кнопки.
- Ссылка в разметке работает как обычная ссылка: фокус, Enter, переход.
- Иконке без текста имя для скринридера задаёт приложение. Декоративные иконки
  скрыты от скринридера.
- Подсказка объявляется как подсказка и связана с элементом.

## Граничные случаи

- Длинный текст переносится по правилам окружения.
- Неразрывный пробел — только через `&nbsp;`.
- Иконка не переносится; при нехватке места ведёт себя как символ текста.
- Многоточие, межстрочный интервал и выделение текста — от окружения.

## Не определено

- `UNKNOWN`: точное число иконок в каталоге (оценка — около 5 000).

## Критерии соответствия

- [ ] `Text` — строчный элемент; шрифт, кегль, межстрочный, отступы, цвет, фон,
      рамка, тень — из окружения.
- [ ] Разметка: `**жирный**`, `*курсив*`, `***жирный курсив***`,
      `~~зачёркнутый~~`, `` `код` ``, `[ссылка](адрес)`,
      `[ссылка](адрес "заголовок")`, `&nbsp;`; остальное — как есть; только в
      строке `value`.
- [ ] Единственная своя настройка вида у `Text` — `fontWeight`.
- [ ] `Icon` берёт цвет, кегль и межбуквенный интервал из окружения; имя
      `ti ti-…`; начертание всегда 400.
- [ ] Иконка рядом с текстом — на базовой линии; в виджете — в квадратном слоте,
      по центру.
- [ ] `as` не меняет вид; флаги валидации не меняют цвет.
- [ ] Подсказка при наведении и фокусе.
- [ ] Иконка без текста без имени не объявляется; декоративные скрыты.
- [ ] `noBootstrap` вид не меняет.
