# Журнал изменений

Свежая версия — сверху. Формат записи: **версия — дата — изменения по частям**.
Названия частей — как в описи `docs/components/INDEX.md`. Типы изменений:
`добавлено` · `изменено` (было → стало) · `удалено` ·
`переименовано/перенесено` · `правка текста` (смысл не менялся, переделывать не
нужно).

## 1.3.0 — 2026-10-17

### Реорганизация каталога

Каталог оформлен как npm-пакет документации для ИИ-агентов: манифест,
корень набора `docs/`, описи в каждой папке, метаданные в каждом файле, файлы не
длиннее 300 строк. Пути в записи — новые, кроме удалённых файлов.

Все файлы приведены к единому формату: одинаковые разделы в одном порядке,
числа и цвета в таблицах, цвета в формате «роль, Light, Dark». Из текста убраны
детали реализации (обработчики, служебные свойства, внутреннее устройство).
Значения, которые меняют уже собранный виджет, не менялись, кроме мест,
перечисленных ниже. Неподтверждённые места помечены `UNKNOWN` в разделах
«Не определено».

**Добавлено**

- Словарь (`docs/glossary.md`) — термины всех файлов.
- Описание каталога (`docs/INDEX.md`) — разделы «Как устроен каждый файл» и
  «Раздел спецификации в отдельном файле», маршруты «задача → файлы».
- Манифест пакета (`package.json`, поле `agentDocset`): id `design-system`,
  корень набора `docs`.
- Опись основ (`docs/foundations/INDEX.md`).
- Опись виджетов (`docs/components/INDEX.md`) — раздел «Файлы» со всеми файлами
  спецификаций.
- Все файлы: блок метаданных в начале — `title`, `summary`, `read_when`,
  `keywords`, `related`.

**Удалено**

- Токены (`tokens.json`) — убраны из каталога: это экспорт альфа-версии новой
  дизайн-системы, не текущей. Значения цветов — в разделах «Цвета»
  спецификаций и в основах.
- `Portal`, `MaybePortal`, `PortalContainer` (`components/portal.md`) —
  спецификация удалена: технический слой без вида. Имена остались в инвентаре,
  раздел «Технический слой».
- `AutumnList`, `AutumnListSpacer` (`components/list.md`) — спецификация
  удалена: движок без вида. Имена остались в инвентаре, раздел «Технический
  слой».
- `ErrorBoundary` (`docs/components/bsod.md`) — подробное описание удалено; в
  спецификации `BSOD` остался абзац «Когда показывается».
- Служба уведомлений `makeAutumnNotifications` (`docs/components/notifications.md`) —
  описание внутреннего устройства удалено; осталось видимое поведение.
- Инвентарь (`docs/components/INDEX.md`) — убраны метрики и цвета, которые
  дублировали спецификации; осталось: имя, назначение, класс, файл.

## 1.0.0 — 2026-10-06

Первая версия, переданная команде разработки.

**Добавлено**

- Основы (`foundations/`): палитра, типографика, отступы и сетка, формы и
  границы, тени и глубина, motion, слои, фокус, иконки, глобальный вид страницы,
  темы, кросс-виджетные режимы.
- Токены: `tokens.json`.
- Виджеты (`components/`): 30 спецификаций и «Инвентарь и классификация
  виджетов».

**Перенесено (без смены смысла)**

- Рабочие материалы вынесены за пределы каталога: прогресс, открытые вопросы,
  расхождения «код ↔ Figma», срез Figma, скрипт сборки токенов.
  (`discrepancies.md` — заметки о несовпадении спеки с источником, не норма.)
- Разделы README про метод, шаблон спецификации, готовность виджета, глоссарий и
  источник истины вынесены из каталога.
- Правило «размер по умолчанию `m`» и режим `noBootstrap` вынесены из README в
  `foundations/widget-modes.md` (теперь адресуемая часть).

**Правка текста (смысл не менялся)**

- Из основ и спецификаций виджетов убраны ссылки на вынесенные рабочие файлы.
