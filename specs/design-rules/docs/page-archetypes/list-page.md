## Назначение

Страница раздела, показывающая коллекцию однотипных объектов таблицей с поиском и
действиями. Использовать для любой сущности-списка (подписчики, ноды, соединения).

## Схема компоновки

Вариант A (Subscribers):
```
┌────────────────────────────────────────────┐
│ Menu(256) │ Content                        │
│           │  Header: breadcrumbs «Subscribers»
│           │  [btn primary][search………]     │
│           │  card: ◈ Node_A  ⋯ версия      │
│           │    ┌ таблица (шапка + строки) ┐│
│           │    └⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯⋯┘ │
│           │  card: ◈ Node_B …              │
└────────────────────────────────────────────┘
```

Вариант B (Instances):
```
┌────────────────────────────────────────────┐
│ Menu(72)│ Content                         │
│         │  Title «Instances»               │
│         │  Tabs ──────────────────────    │
│         │  [Search…]          [act][act]   │
│         │  group «Group5 …» (edit/trash)   │
│         │    ┌ таблица ──────────────┐    │
│         │  ▾ Drop-down Table (свёрн.) │    │
└────────────────────────────────────────────┘
```

## Правила

**[Общее]** Список — таблица с шапкой и строками, на всю рабочую ширину; колонки
фиксированы по ширине (`table-cell`).

**[Общее]** Над таблицей — строка управления: поиск (слева/по центру) и кнопки
действий (создать/фильтр — справа или слева в начале строки).

**[Общее]** Поиск — поле с иконкой поиска и плейсхолдером «Search».

**[Только B]** У списка может быть строка вкладок (`Tabs Local`) под заголовком,
переключающая подразделы списка.

**[Только A]** У списка возможна группировка контента в отдельные карточки с
заголовком-иконкой и футером `Card-footer`.

**[Общее]** Пагинация/счётчик отображается текстом под таблицей («Routes: 6 of 77»).

## Используемые компоненты

`Menu`, `button--light-primary`, `input--light-secondary` / `Icons / 16px / Поиск`,
`table-cell`, `Table Head`, `Row`, `Tabs`/`Tabs Local`, `Drop-down Table`,
`Card-footer`, `Icon Buttons`, `Component 243/244`.

## Вариации и расхождения

- **[Только A]** список подписчиков с карточками-конфигурациями.
- **[Только B]** сгруппированные таблицы (`Table 1`, `Table 2`) с `Drop-down Table` —
  сворачиваемая секция/подтаблица.

## Примеры из референсов

- A — App Connections.
