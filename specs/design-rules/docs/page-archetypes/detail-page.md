## Назначение

Страница сущности-конфигурации (нода, маршрут, профиль): просмотр и редактирование
состава через карточки, табы-версии и вложенные таблицы.

## Схема компоновки

```
│ Menu(256) │ Content                          │
│           │  Header: breadcrumbs «Site configuration / Node 1 / Version 1»
│           │  Tabs (версии/разделы) ────────
│           │  [Button]                       │
│           │  card «Version 1»:               │
│           │    ◈ имя  ⋯ версия-метаданные   │
│           │    ┌ таблица ──────────────────┐
│           │    │ голова (36) + строки (36)  │
│           │    │ действие: иконки в конце    │
└──────────────────────────────────────────────┘
```

## Правила

**[Общее]** Вверху — хлебные крошки до сущности. Под ними — строка вкладок
(`Tabs`) по версиям/подразделам; у вкладок — значок «+» (`Icon / plus_24px`) справа.

**[Общее]** Тело — таблица с шапкой (`Table Header`, 36px) и строками; в последней
колонке — иконки действий в строке (`download`, `pencil`, `copy`, `trash`).

**[Только A]** Каждая конфигурация — карточка: слева иконка + имя (напр. «Node_A»)
и кнопка-иконка edit; справа строка «`<type> configuration: <name> | <N> Version
from <дата> <время>`».

**[Только A]** Пустое состояние внутри таблицы: заголовок + подсказка + кнопка
(напр. «Нет действующей версии» / «Для создания версии добавьте CEX profiles» +
кнопка).

## Используемые компоненты

`Menu`, `Tabs`, `Button`, `table-cell`, `Table Header`, `Icon / plus_24px`,
`Icon / pencil_24px`, `Icon / download_24px`, `Icon / copy_24px`, `Icon / trash_24px`,
`Icon / check_24px`, `Card-footer`, `Input & Select` (при редактировании).

## Вариации и расхождения

- **[Только A]** табы-версии «Tab 1..4 + „+“», пустое состояние внутри таблицы.
- **[Расхождение]** состав иконок действий в строке шире в A (check/download/pencil/
  copy/trash), чем в B (edit/trash на уровне блока).

## Примеры из референсов

- A — Routing Configurations / Edit Configuration.
- A — App Configurations / Edit CEX profile.
