## Назначение

Создание составной конфигурации в несколько шагов/вариантов (например, создание
профиля DSP/CEX, добавление соединения) с выбором транспорта в начале.

## Схема компоновки

```
Menu │ Breadcrumbs «… create DSP profile …»
     │ dropdown [transport: SCTP | TCP]   (386×72)
     │ ┌ шаг: поля формы ────────────────┐
     │ │ Input & Select / dropdown …      │
     │ │ …                               │
     │ └─────────────────────────────────┘
     │ Footer: [кнопки]
```

## Правила

**[Только A]** Мастер начинается с выбора **транспорта** через `dropdown`
(386×72) — варианты SCTP/TCP порождают отдельные экраны одного шаблона.

**[Только A]** Набор полей — `Input & Select` + `dropdown`, раскладывается по
нескольким колонкам (535px, 421px).

**[Только A]** Итоговый шаблон дублируется под каждый вариант транспорта отдельным
экраном 1920×1080 (`Create DSP profile / SCTP`, `/ TCP`; `Add Connection /
SCTP-Client`, `/ TCP-Server`, `/ SCTP-Server`).

## Используемые компоненты

`dropdown`, `Input & Select`, `Textarea`, `Footer`, `Menu`, `Button`, `Tabs`.

## Вариации и расхождения

- **[Только A]** присутствует в A; в B мастера не найдены (используются модалки).

## Примеры из референсов

- A — 1 App Configurations / Create DSP profile / SCTP.
- A — 2 App Configurations / Create DSP profile / TCP.
- A — Peer Table / Add Connection / SCTP - Client, TCP - Server,
  SCTP - Server, TCP - Server.
