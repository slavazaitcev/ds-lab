## Назначение

Создание или редактирование одной сущности (нода, профиль, конфигурация). Форма
может быть развёрнута на странице или в модалке.

## Схема компоновки

Форма в модалке (B — Edit node, A — «Данные клиента / Основные»):
```
┌── Modal (480) ────────────┐   ┌── Modal (700) ────────────────┐
│ Title            ✕ (16)   │   │ Title «Creating CEX»   ✕ (24) │
│ ┌ Input & Select ───────┐ │   │ ┌─ Input & Select (62px) ──┐   │
│ ┌ Input & Select ───────┐ │   │ │ … (повторяется 11×)      │   │
│ [Cancel]        [Save]   │   │ └───────────────────────────┘   │
└───────────────────────────┘   │ Footer (76px) — кнопки         │
                                └────────────────────────────────┘
```

Форма на странице (A — создание):
```
Menu │ Breadcrumbs «…»
     │ Tabs / dropdown (транспорт SCTP|TCP)
     │ ┌─ Input & Select ┬─ Input & Select ─┐   (поля в 2–3 колонки)
     │ │ Textarea        │                  │
     │ │                  │                  │
     │ Footer: [кнопки справа]
```

## Правила

**[Общее]** Поле формы — компонент `Input & Select` (высота 62px, лейбл + контроль).
Многострочный ввод — `Textarea`.

**[Общее]** Лейблы — **над** полем (внутри `Input & Select`); группы полей могут
иметь `Section Title`.

**[Общее]** Кнопки действия — внизу (`Footer`/`Buttons`): **Cancel слева, Save/Submit
справа**.

**[Общее]** В модалке поля идут **в одну колонку** на всю ширину; на странице —
возможно **несколько колонок** (поля 535px и 421px рядом).

**[Общее]** Закрытие модалки — иконка ✕ (`Icon / x-close_16px` в B, `Icon / x-close_24px` в A).

**[Расхождение]** Размер модалок-форм: B — 480px (два поля), A — 700px (до 11 полей).

## Используемые компоненты

`Input & Select`, `Textarea`, `Footer`, `Button`/`Component 13`, `Component 14`,
`Icon / x-close_16px`, `Icon / x-close_24px`, `Tabs`, `dropdown`, `Input group / create node`.

## Вариации и расхождения

- **[Только A]** модалка «Данные клиента / Основные» 700px с 11 полями и `Footer`.
- **[Только A]** форма на странице с dropdown выбора транспорта.
- **[Только B]** «Modal - Edit node» 480×296 (заголовок + 2 поля + кнопки).
