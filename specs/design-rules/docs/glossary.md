## Назначение

Объясняет термины, которые используются во всех файлах. Каждый термин означает
одно и то же во всех файлах.

## Значения

| Термин | Что значит |
|---|---|
| A, B | две обезличенные референсные админки, по образцу которых строится новое приложение |
| Архетип страницы | повторяемая схема целой страницы (список, детали, форма, мастер) |
| Паттерн | повторяемая сборка виджетов под сценарий внутри страницы |
| Оболочка | каркас экрана: меню, контент, шапка, крошки, футер |
| [Общее] | статус утверждения: одинаково решено в A и B |
| [Только A] | статус утверждения: встречается только в A |
| [Только B] | статус утверждения: встречается только в B |
| [Расхождение] | статус утверждения: есть в обоих проектах, но решено по-разному |
| [Несогласованность] | разные экраны внутри одного проекта сделаны по-разному |
| Рабочая ширина | ширина контента за вычетом боковых отступов |
| Референс | разобранный экран A или B в [reference](reference/INDEX.md) |
| Эталонный код | сырой код экрана в fenced-блоке `tsx`; точные размеры, цвета, шрифты и тексты «как есть» |
| `Generic `Component NN`` | неназванный компонент макета; имена деталей не раскрываются |
| Счётчик списка | текст вида «1 - 50 of 200» под таблицей |
| «как есть» | значение из макета без правок; не норма |

## Правила применения

- Если в тексте встречается непонятный термин, ищите его здесь.
- Новый термин сначала добавляется сюда, потом используется в файлах.
- Референс — иллюстрация, а не норма: при расхождении верна документация правил.
