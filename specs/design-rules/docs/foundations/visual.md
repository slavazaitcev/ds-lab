## Статусы утверждений

[Общее] · [Только A] · [Только B] · [Расхождение] · [Несогласованность].

## Типографика

**[Общее]** Семейство шрифта — **Roboto**. Иерархия задаётся парой «размер/высота + вес»:

| Токен Figma | Размер/высота строки | Вес |
|---|---|---|
| `Tittle 1` | 24/28 | Medium (A) / Bold (B) |
| `H1 / Bold` | 16/20 | Bold (700) |
| `Headline / Medium` | 16/20 | Medium (500) |
| `P/Medium`, `P/Regular` | 14/20 | 500 / 400 |
| `Caption 1/Medium`, `Caption 1/Regular` | 13/16 | 500 / 400 |

**[Расхождение]** Заголовок первого уровня: A — `Tittle 1 / Medium`, B —
`Tittle 1 / Bold`.

Правила:

**[Общее]** Заголовок раздела набирается токеном 24/28; заголовок страницы в
списках — 16/20 (H1); основной текст и значения таблиц — 14/20; подписи и
вторичные подписи — 13/16.

## Цветовые роли

**[Общее]** Общий набор цветовых переменных (одна палитра на оба проекта):

| Токен | HEX | Роль |
|---|---|---|
| `Gray/100` | #141F2F | основной текст / «чернила» |
| `Gray/70` | #5F6772 | вторичный текст |
| `Gray/60` | #79818B | приглушённый текст |
| `Gray/20` | #DEE0E3 | границы, разделители |
| `Gray/10` | #ECEDEF | границы/фон (B) |
| `Bg-gray-light` | #F1F2F3 | фон поверхностей |
| `White` | #FFFFFF | поверхность карточек |
| `Blue Light/100` | #5D9AF4 | акцент (синий) |
| `Red/100` | #E61E43 | danger / ошибка |
| `Green / 100` | #27AE60 | success |
| `Transparent` | #D9D9D9 | заглушка |

Правила:

**[Общее]** Фон страницы светлый (`Bg-gray-light`), поверхности/карточки —
`White`, границы и разделители — `Gray/20`. Основной текст `Gray/100`.

**[Общее]** Акцент — синий (`Blue Light/100`); опасные действия и ошибки — красный
(`Red/100` #E61E43); успех — зелёный (`Green / 100` #27AE60).

**[Только B]** В выборке B присутствует `Green / 100` (#27AE60) для статусов успеха
и `Gray/10` (#ECEDEF); в выборке A этих токенов нет (не обязательно отсутствуют —
просто не встретились на экране).

**[Только A]** В выборке A есть `Gray/70` (#5F6772) и `Headline / Medium` 16/20.

## Отступы и ритм

**[Общее]** Базовый модуль отступа — переменная `m` = 20. Реально используемые
отступы в макетах кратны 4/8: 8, 16, 20, 24, 32, 36, 40.

Правила:

**[Общее]** Между боковой навигацией и контентом отступа нет — контент примыкает
к меню; внутри контента боковой отступ 24px (рабочая ширина = ширина контента − 48).

**[Общее]** Строки таблиц: 36px (компактные) или 40px; высота шапки таблицы
36–72px (72px при двухуровневой шапке).

**[Общее]** Поля формы (`Input & Select`) высотой 62px, шаг между полями по
вертикали 78px.

## Радиусы и тени

Не установлены из переменных (в metadata нет fill/radius). Косвенно: карточки с
прямыми или малыми радиусами, тени не выражены (плоский светлый интерфейс).
