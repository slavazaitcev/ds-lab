## Статусы утверждений

[Общее] · [Только A] · [Только B] · [Расхождение] · [Несогласованность].

## Layout

```
[ Menu | Content                    ]
| 256  |        1664               |   ← A (Menu развёрнуто)
|  72  |        1848               |   ← B (Menu свёрнуто)
```

**[Общее]** Экран — канва **1920×1080**. Слева вертикальная навигация `Menu` на всю
высоту, справа область `Content`.

**[Расхождение]** Ширина навигации: **A — 256px** (полное меню), **B — 72px**
(иконочная рейка). Контент соответственно 1664 (A) и 1848 (B).

## Сетка и ширины

Правила:

**[Общее]** Контент имеет горизонтальный отступ 24px с обеих сторон: рабочая ширина
A = **1616**, B = **1800** (ширина контента − 48).

**[Общее]** Элементы внутри контента выравниваются в одну колонку на всю рабочую
ширину; блоки идут сверху вниз без сетки из нескольких колонок (кроме полей формы —
см. [forms.md](../patterns/forms.md)).

## Шапка / заголовок страницы

**[Только B]** `Main Header Component` (двух- или трёхрядная шапка):
1. `Header` (40px) — `Title` слева («Instances»), `Empty` справа (пустое место).
2. `Tabs Local` (30px) — `Tabs` под заголовком.
3. `Middle Active` (36px) — слева `Search` (`Icons / 16px / Поиск` + текст «Search»),
   справа кнопки действий (`Component 244` + `Component 243`).

**[Только A]** Шапка иная: хлебные крошки сверху — `Breadcrumbs Container` с текстом
(«Subscribers», «Site configuration», «Node 2 configuration»), рядом скрытая иконка
`Icon / pencil_24px`; затем строка действий `button--light-primary` + поиск
`input--light-secondary`.

Правила:

**[Общее]** Заголовок/контекст страницы находится **вверху слева** области контента.

**[Общее]** Если у сущности есть версии/табы, они идут **под заголовком** отдельной
строкой (компонент `Tabs`/`Tabs Local`).

## Хлебные крошки

**[Только A]** Хлебные крошки — строка из текста, уровни через ` -> `:
«Subscribers -> Node_A -> Status link», «Site configuration / Node 1/ Version 1»
(в одном случае разделитель « / », в другом « -> » — см. [Несогласованность]).

**[Только B]** Крошки без отдельного компонента; в текстах встречается формат
«Routing -> ID-Configuration name | Version 1 -> SCCP 0 | Name».

**[Несогласованность]** В A разделитель хлебных крошек нестабилен: « -> » (Status
link) и « / » (Site configuration). Чаще « -> ».

## Футер

**[Только A]** У карточки конфигурации нижняя граница закрывается `Card-footer` (72px) — футер карточки (не страницы). Глобального футера страницы нет ни в A, ни в B.

## Закрепление / прокрутка

Установлено косвенно: шапка и строка поиска — верхние (закреплённые области);
таблицы/карточки прокручиваются внутри контента. Точное поведение закрепления не
подтверждено.
