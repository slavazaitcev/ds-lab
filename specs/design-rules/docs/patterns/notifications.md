## Статусы утверждений

[Общее] · [Только A] · [Только B] · [Расхождение] · [Несогласованность].

## Виды

**[Только B]** В текстах B различаются типы уведомлений:
- Успех: ««Group 5» App node has been successfully deleted.»
- Ошибка: ««Group 5» App node has active subscriber.»
- Информационное: «Informational notification»
- Ошибка: «Error message»

**[Только B]** Цвет: успех `Green / 100`, ошибка `Red/100` (по палитре).

## Стиль текста

**[Только B]** Сообщения — законченные предложения, содержат имя объекта в кавычках
(«Group 5»). Успех — прошедшее время «has been …»; ошибка — «has active …».

## Позиция / длительность

Не установлены (компонент toast в metadata не детализирован).

## A

В изученных экранах A явных toast-текстов нет.
