## Статусы утверждений

[Общее] · [Только A] · [Только B] · [Расхождение] · [Несогласованность].

## Боковое меню

**[Общее]** Вертикальная панель навигации `Menu` слева, на всю высоту экрана.

**[Расхождение]** A — полное меню **256px**; B — свёрнутая иконочная рейка **72px**.

Пункты меню в metadata не детализированы (компонент `Menu` без внутренней структуры).

## Хлебные крошки

**[Только A]** Крошки — строка текста, уровни через разделитель.

**[Несогласованность]** Разделитель в A нестабилен: « -> » и « / ». Примеры:
«Subscribers -> Node_A -> Status link», «Site configuration / Node 1/ Version 1».

## Вкладки (табы)

**[Общее]** Вкладки `Tabs`/`Tabs Local` — под заголовком страницы, горизонтально.

**[Только A]** Табы-версии с «+» (`Icon / plus_24px`) в конце каждой вкладки
(добавление версии).

**[Только B]** `Tabs Local` — переключение подразделов списка (под `Header`).

## Возврат

**[Общее]** Стрелка-назад `Icon / arrow-left_24px` предусмотрена в крошках (скрытая
в изученных экранах).
