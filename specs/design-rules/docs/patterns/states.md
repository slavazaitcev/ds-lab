## Статусы утверждений

[Общее] · [Только A] · [Только B] · [Расхождение] · [Несогласованность].

## Пустое состояние

**[Общее]** Пустое состояние — заголовок + пояснение + кнопка-призыв, по центру
области.

**[Только A]** Примеры: «Нет действующей версии» / «Для создания версии добавьте
CEX profiles» + кнопка (внутри таблицы). Отдельный экран «Первый вход в раздел если
нет никаких Нод».

**[Только B]** Пример: «Configuration signalling: No version» / «Configuration
routing: No version» (строка-версии в заголовке блока = нет версии).

## Загрузка / скелетон

Не встречены на изученных экранах.

## Ошибка / нет доступа

**[Только B]** Текст ошибки — «Error message», «Informational notification».
Формат уведомлений — см. [notifications.md](notifications.md).

## Успех (уведомления)

**[Только B]** Тост-успех: ««Group 5» App node has been successfully deleted.»

## Ошибка действия

**[Только B]** Тост-ошибка: ««Group 5» App node has active subscriber.»
