## Статусы утверждений

[Общее] · [Только A] · [Только B] · [Расхождение] · [Несогласованность].

## Раскладка полей

**[Общее]** Базовое поле — `Input & Select` (высота **62px**, лейбл над контролом).

**[Общее]** Лейблы — **сверху** поля.

**[Общее]** Шаг между полями по вертикали — **78px** (в столбце).

**[Расхождение]** Число колонок: в **модалке — одна колонка** на всю ширину (A и B);
на **странице** (A, мастера) поля раскладываются **в 2–3 колонки** (ширины 535px / 421px).

## Группировка в секции

**[Только A]** Группы полей имеют заголовок-секцию (`Section Title`, напр.
«Timeouts», «Общая информация»).

## Обязательность, подсказки, ошибки

- Обязательность маркером в metadata не определяется (скрыто внутри `Input & Select`).
- Placeholder-тексты реальные: «Vendor specific appliction id», «This node is located
  in Server Room A, Rack 3, slot 5», «Default».
- Ошибки поля — не встречены явно.

## Кнопки

**[Общее]** Кнопки внизу формы: **Cancel слева, подтверждение (Save/…) справа**.

**[Общее]** В модалке — `Buttons` (справа `Component 13` = secondary + `Component 14`
= primary). В A на странице — `Footer` (76px).

## Форма в модалке vs на странице

**[Расхождение]** B редактирование сущностей — **только модалкой** («Modal - Edit
node App», 480px). A — модалка (700px, создание CEX) **и** страница-форма (мастера).

## Индикатор создания (заглушка полей)

Стандартные «Label»/«Placeholder»/«Value» — это fill-заглушки текстов в компонентах
(«Text», «Cell», «Placeholder»), не реальные копирайты — не принимать за контент.
