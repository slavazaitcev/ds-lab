## Статусы утверждений

[Общее] · [Только A] · [Только B] · [Расхождение] · [Несогласованность].

## Модалка (форма)

**[Общее]** Модалка — по центру экрана, заголовок + ✕-закрытие + тело + кнопки.
Радиус/затемнение не заданы; затемнение — слой `Rectangle 258` (скрытый, задник).

**[Общее]** Закрытие — иконка ✕: `Icon / x-close_16px` (B) / `Icon / x-close_24px` (A).

**[Расхождение]** Ширина: B — 480px (двухполезная «Modal - Edit node»);
A — 700px («Данные клиента / Основные»).

## Карточка-подтверждение

**[Только B]** Удаление — карточка `Card` (не классическая модалка): `Header` +
`Body` (текст) + `Buttons`. Присутствует на экране `Delete Node` поверх
страницы.

## Диалог

**[Только A]** Компонент `Dialog` (432×210) встречается на странице Node
Configuration.

## Tooltip / Cursor

**[Только B]** В макете hover-состояний присутствуют `Tooltip` + `Cursor` (0532),
показывающие поведение при наведении.

## Сводка выбора

| Сценарий | A | B |
|---|---|---|
| Редактирование | модалка 700px / страница | модалка 480px |
| Подтверждение удаления | `Dialog` | `Card` |
| Hover-подсказка | — | `Tooltip` + `Cursor` |
