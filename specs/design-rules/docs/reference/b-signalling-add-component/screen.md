## Источник

Проект B. Кадр **1920 × 1720** (длинная прокручиваемая форма).

## Роль референса

Каноничная длинная форма создания сущности. Дополняет
[form-page.md](../../page-archetypes/form-page.md) и [forms.md](../../patterns/forms.md).

## Назначение

Создание составного компонента сигнализации. Форма разбита на белые карточки
-секции, идущие одна под другой; вверху — «шапка» формы с именем и кнопками
управления.

## Схема компоновки

```
┌──────────┬────────────────────────────────────────────────────────────┐
│  Menu    │  Content (bg #ECEDEF, px 24, pt 24)                        │
│  256 px  │  Signalling -> Компонент                                    │
│          │  (заголовок: префикс #79818B + имя #5D9AF4)                │
│  App     │  ┌ Head (белая карточка, p 20, r8) ───────────────────────┐│
│          │  │ Component name *   Component Id    SSU *                ││
│          │  │ [input h36]        [input h36]      [select ▾ h36]      ││
│          │  │                       [Delete] [Close] [Create]         ││
│          │  │  (кнопки)          [input] [textarea]  [🗑]            ││
│          │  │  ────── секция 1 ──  [input] [textarea]  [🗑]          ││
│          │  │  ────── секция 2 ────────────────────────────────── ││
│          │  │  ────── секция 3 ────────────────────────────────── ││
│          │  │  ────── секция 4 ────────────────────────────────── ││
│          │  └─────────────────────────────────────────────────────────┘
└──────────┴────────────────────────────────────────────────────────────┘
```

## Оболочка

Боковое меню 256 px, продукт `App`. Активный пункт `Signaling` (заливка `#5D9AF4`).
Состав меню — как в [b-point-codes](../b-point-codes/INDEX.md), ширина отличается (256 против 320).

## Регионы

**Заголовок-цепочка** — крупный заголовок 24 / Bold:

серая часть `Signalling -> Компонент` (#79818B) и варьируемая часть `Компонент` (#5D9AF4). Отдельной строки хлебных крошек нет.

**Шапка формы**: белая карточка, padding 20, радиус 8. Сверху — три поля в ряд
(зазор 24), подпись над полем (14 / Regular, `#5F6772`; звёздочка
обязательности `*` — `#E61E43`):
- `Component name *` — input, плейсхолдер `Placeholder`;
- `Component Id` — input, плейсхолдер `Placeholder`;
- `SSU *` — select, значение `Not selected`, иконка `chevron-down_20px`.

Поле ввода: фон `#ECEDEF`, высота 36, радиус 8, текст 14 / Regular.
Справа — группа кнопок (`Buttons group`, h 36): `Delete` (неактивна, `opacity 50`),
`Close` (текстовая, `#5D9AF4`), `Create` (неактивна: заливка `#B5B9BF`, `opacity 50`, белый текст). Кнопки — `Component 11`.

**Секции-карточки** (все — белые, padding 20, радиус 8, зазор между секциями 16,
внутри карточки заголовок 16 / Medium `#141F2F` + поля с зазором 24):
- `Parameter`: поля `OPC *` (select), `SCTP profile` (select), `Bandwidth` (input,
  иконка `info-circle`); справа от `OPC` — переключатель `VAR` / `VAL`
  (активный `VAR` — `#5D9AF4`, неактивный `VAL` — `#B0B4BA`).
- `Parameter Local IP`: `Local primary IP *`, `Local Port *`,
  `Local secondary IPs` (иконка `info-circle`).
- `Parameter Remote IP` (заголовок + иконка `info-circle` + кнопка-чип `Add`,
  фон `#EFF5FE`, текст `#5D9AF4`): повторяющиеся под-карточки `Card 1` / `Card 6`:
  `Allowed remote port` (input) + `Allowed remote IP *` (textarea, плейсхолдер
  `Enter a description…`), в углу счётчик символов и кнопка-корзина
  (`Icon / trash_24px`); между карточками — разделитель.

**Футер** — в макете скрыт (`hidden`).

## Что иллюстрирует

- Архетип «форма создания»: заголовок-цепочка → шапка с ключевыми полями и
  кнопками → секции-карточки.
- Раскладку полей: подпись **над** полем; сетка до трёх колонок (376 px / `flex`);
  отступ между полями 24, между подписью и полем 6.
- Обязательность (`*`, `#E61E43`), подсказки через иконку `info-circle`, дефолтные
  значения прямо в плейсхолдере (`Default value is …`).
- Повторяемые под-карточки с кнопкой удаления и разделителем между ними.
- Иерархию кнопок в шапке: неактивная опасная, текстовая вторичная, недоступная
  основная.
