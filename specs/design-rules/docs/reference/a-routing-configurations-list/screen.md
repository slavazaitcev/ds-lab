## Источник

Проект A. Кадр **1920 × 1080**.

## Роль референса

Список конфигураций с вкладками-версиями и колонкой действий
строки. Дополняет [list-page.md](../../page-archetypes/list-page.md),
[tables-and-lists.md](../../patterns/tables-and-lists.md), [navigation.md](../../patterns/navigation.md).

## Назначение

Раздел «Routing configurations» приложения A: таблица сохранённых конфигураций с
датами жизненного цикла и версией. Сверху — вкладки по узлам и кнопки создания/импорта.

## Схема компоновки

```
┌──────────┬────────────────────────────────────────────────────────────┐
│  Menu    │  Content (bg #F1F2F3, px 24, pt 20)                        │
│  256 px  │  Routing Configurations            (24 / Medium #141F2F)      │
│          │  Node_A   Node_B                                             │
│     ───── (вкладки; активная — синий текст + линия 2 px)                │
│  App     │  [＋ Add Configuration] [⇩ Import]  (кнопки-аутлайн)         │
│          │                                                            │
│ • Subscribers                                                          │
│ • Routing     │  ┌ Table (w 1616, bg white, border #DEE0E3, r8) ─────────┐
│   конфигурации │  │ Name │ Creation date │ Update date │ Apply date │ Ver │
│ • App         │  │──────┼───────────────┼─────────────┼───────────┼─────│
│   Configurations │  Config_05 │ 2025.05.28 15:20 │ … │ 1003 │ 1004│
│ • Node         │  Config_06 │ 2025.05.29 10:15 │ … │ …   │ …  │
│   Configurations │  … 21 строка по 36 px                                 │
│ • Topology Hiding│  (иконочные действия в последней колонке)              │
│                │  └───────────────────────────────────────────────────┘
│  Account       │  ┌ Card-footer (h 72) ────────────────────────────────┐
└──────────┬───────────────────────────────────────────────────────────────┘
```

## Оболочка

- **Меню, 256 px, белый фон.** Продукт — `App`. Пункты (h 40, r 8): `Subscribers`,
  `Routing configurations` (активен: заливка `#5D9AF4`, белый текст),
  `App Configurations`, `Node Configurations`, `Topology Hiding`. Внизу — `Account`.
- **Контент** — фон `#F1F2F3`. Отступы: `pt 20`, `px 24`, `pb 24`.

## Регионы

**Заголовок.** `Routing Configurations` (24 / Medium, `#141F2F`).

**Вкладки.** Две вкладки-версии `Node_A` (активна: текст `#5D9AF4`, подчёркивание
`#5D9AF4`, 2 px) и `Node_B` (текст `#79818B`, подчёркивание скрыто). Рядом справа —
пустая зона действий. Вкладки собраны из `Tabs`.

**Кнопки действий.** Две кнопки-аутлайна (`button--light-primary`): `Add
Configuration` (иконка `+`) и `Import`. Вид: прозрачный фон, рамка `#5D9AF4`,
радиус 4, текст `#5D9AF4` 13 / Medium, иконка 16, высота 28.

**Таблица** (ширина 1616, высота 792, белая, рамка `#DEE0E3`, радиус 8):
- Шапка (`Table Head`, фон `#F8F8F8`): 14 / Medium `#5F6772`, ячейки с рамками
  `border-b` и `border-r` `#DEE0E3`, padding 12/8. Колонки равной ширины (≈282):
  `Name`, `Creation date`, `Update date`, `Apply date`, `Version`; последняя
  (204 px) — пустая, под действия.
- Строки (h 36): данные 14 / Regular `#141F2F`; колонки с датами в формате
  `2025.05.28 15:20`; `Version` — число (`1003`, `1004`, …).
- Последняя ячейка строки — 5 иконочных действий по 36 × 36 (иконки 20 × 20,
  зазор 4): `check`, `download`, `edit`, `check`, `trash`. Часть действий без
  ссылки (`<a>`), часть — обычные контейнеры.
- Всего 21 строка.

**Футер** (`Card-footer`, высота 72) — общий для списка; в кадре пустой
(пагинация не показана).

## Что иллюстрирует

- Оболочку A с узким меню 256 px.
- Вкладки-версии (`Node_A` / `Node_B`) как смену контекста внутри одного списка.
- Таблицу с колонками дат жизненного цикла и колонкой из нескольких иконочных
  действий в конце строки; формат дат `ГГГГ.ММ.ДД чч:мм`.
- Кнопки-аутлайны бренда для действий над списком (`Add Configuration`,
  `Import`) — в отличие от заливных primary-кнопок B.
