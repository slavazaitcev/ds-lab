## Источник

Проект B. Кадр **1920 × 1080**.

## Роль референса

Каноничный экран со списком (таблица + поиск + тулбар действий +
пагинация). Дополняет [list-page.md](../../page-archetypes/list-page.md) и
[tables-and-lists.md](../../patterns/tables-and-lists.md).

## Назначение

Раздел «Point Codes»: список однотипных записей кодов точек. Сверху — заголовок
раздела, главное действие создания и поиск; ниже — таблица; внизу — пагинация.

│          │  │                                                       │ │

## Оболочка

- **Боковое меню, 320 px, фон белый.** Верх — название продукта `App`. Пункты (h 40,
  r 8, px 10): `Instances`, `Signaling`, `Routing`, `Point Codes`, `Profile SCTP`,
  `Check`, `Users`, `Audit`. Активный пункт — заливка `#5D9AF4`, белый текст;
  остальные — текст `#79818B` (14 / Medium). Внизу отдельной группой — `Account`
  (иконка `settings_20px`).
- **Контент** — фон `#ECEDEF`, верхний отступ 20 px, боковые поля 24 px.

## Регионы

**Main Header** (высота 92). Заголовок `Point Codes`. Под ним строка (зазор 16):
- primary-кнопка **`Create codes`** (`Component 244`): заливка `#5D9AF4`,
  белый текст 14 / Medium, иконка 16 + подпись, высота 36, радиус 8;
- строка поиска **`Search`**: `flex-1`, белый фон, рамка `#ECEDEF`, радиус 8,
  высота 36, отступ 12; иконка поиска `Icons / 16px / Поиск` + плейсхолдер
  `Search` (`#79818B`), справа — иконочная кнопка 32 × 32.

**Таблица** (ширина 1552, рамка `#DEE0E3`, радиус 8, на всю ширину).
- Шапка (h 40, фон белый, нижняя граница `#DEE0E3`): 14 / Medium, `#79818B`.
  Колонки: `ID` (96, сортируемая), `Configuration Name` (240, сортируемая),
  `App` (200), `node-a` (200), `node-c` (200), последняя — растягивается.
  Сортировка показана стрелкой `bi:arrow-left-short` 16 × 16.
- Строки (h 40, фон белый, граница снизу `#DEE0E3`), данные 14 / Regular
  `#141F2F`:
  - 1-я ячейка — номер;
  - 2-я — имя конфигурации;
  - 3–4-я — `●`-индикатор 12 × 12 (радиус 4) + число. Цвет индикатора кодирует
    состояние: зелёный `#27AE60`, жёлтый `#F1B704`, серый `#9298A0`;
  - 5–6-я — часто `-`;
  - последняя — действия строки: `pencil_20px` и `trash_20px` (20 × 20, зазор 16).
- Всего 24 строки (Row 1, Row 7 … Row 24). В кадре видна также всплывающая
  подсказка `Tooltip` (141 × 32).

**Футер** (`Card-footer`, высота 72). Пагинация 32 × 32 (радиус 8): стрелка назад
неактивна (`opacity 50`), активная страница `1` — заливка `#5D9AF4`, белый текст;
`2`, `3`, «…», `5`. Справа — селектор размера страницы `50` и подпись
`1 - 50 of 200` (13 / Regular, `#5F6772`).

## Что иллюстрирует

- Оболочку админки B: меню 320 px с активным пунктом через заливку бренда.
- Архетип «страница-список»: заголовок → (главное действие + поиск) → таблица →
  пагинация.
- Таблицу с колонкой индикатора-состояния (цветной квадрат + число) и колонкой
  действий строки (иконки правки/удаления).
- Пагинацию с выбором размера страницы и счётчиком диапазона.
