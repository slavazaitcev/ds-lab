# Журнал изменений

Свежая версия — сверху. Формат записи: **версия — дата — изменения по частям**.
Названия частей — как в описи `docs/INDEX.md`. Типы изменений: `добавлено` ·
`изменено` (было → стало) · `удалено` · `переименовано/перенесено` ·
`правка текста` (смысл не менялся, переделывать не нужно).

## 1.3.0 — 2026-10-17

### Реорганизация каталога

Каталог оформлен как npm-пакет документации для ИИ-агентов: манифест,
корень набора `docs/`, описи в каждой папке, метаданные в каждом файле. Пути в
записи — новые, кроме удалённых файлов. Каталог приведён к правилам
`raw/docset-authoring.md`: каждый файл начинается с блока метаданных —
`title`, `summary`, `read_when`, `keywords`, `related`; в каждой папке —
`INDEX.md` со ссылками на все файлы; в корневом `INDEX.md` — маршруты
«задача → файлы». Заголовков первого уровня в тексте нет, заголовки разделов не
повторяются.

**Добавлено**

- Описание каталога (`docs/INDEX.md`) — разделы «Как читать», «Статусы
  утверждений», «Как записаны значения», маршруты «задача → файлы».
- Манифест пакета (`package.json`, поле `agentDocset`): id `design-rules`,
  корень набора `docs`.
- Словарь (`docs/glossary.md`) — термины всех файлов.
- Все файлы: блок метаданных в начале — `title`, `summary`, `read_when`,
  `keywords`, `related`.
- Опись референс-примеров (`docs/reference/INDEX.md`) — папки экранов и их
  подпапки с подписями.
- Эталонный код (`context.tsx`) оформлен как файл `context.md` с fenced-блоком `tsx`.

**Переименовано / перенесено**

- Все файлы каталога: `design-rules/*.md` → `docs/`; корень набора — `docs/`,
  описи — `docs/INDEX.md`.
- Визуальная основа: `01-foundations.md` → `docs/foundations/visual.md`.
- Оболочка приложения: `02-app-shell.md` → `docs/foundations/app-shell.md`.
- Архетипы страниц: `03-page-archetypes/` → `docs/page-archetypes/`.
- Паттерны: `04-patterns/` → `docs/patterns/`.
- Инвентарь компонентов: `05-components-usage.md` → `docs/components-usage.md`.
- Тексты и форматы: `06-content.md` → `docs/content.md`.
- Сводка расхождений: `07-divergences.md` → `docs/divergences.md`.
- Референс-примеры: `reference/` → `docs/reference/`, опись —
  `reference/README.md` → `docs/reference/INDEX.md`.
- Эталонный код: `reference/*/context.tsx` → `docs/reference/*/context.md`
  (код внутри fenced-блока `tsx`).

**Правка текста (смысл не менялся)**

- Все файлы: заголовок первого уровня убран, название — в метаданных; легенда
  статусов в начале каждого файла приведена к единому виду.

## 1.2.0 — 2026-10-13

**Изменено** (обезличивание)

- Удалены ссылки на исходные макеты: ключи и URL внешних файлов и внутренние
  идентификаторы узлов — убраны из `reference/` и нормативных файлов.
- Обезличены имена продуктов и реальные идентификаторы (продукты → «A»/«B»,
  имена узлов → `Node_A`/`Node_B`, реальные имена → нейтральные `Config_*`, `Rule_*`,
  `Account`, `host-*.example.org`, обнулённые числовые диапазоны); имена клиентов и
  операторов заменены на нейтральные. Размеры, цвета, шрифты, структура и число
  строк не затронуты.
- В `reference/*/context.tsx` удалены следы исходных макетов: атрибуты
  `data-node-id`, временные ссылки на ассеты и служебные комментарии.

**Правка текста (смысл не менялся)**

- Из `reference/` и нормативных файлов убраны следы исходных макетов: внутренние
  идентификаторы узлов, ключи файлов и внешние ссылки; названия заголовков
  «компоненты Figma» уточнены без привязки к источнику.

## 1.1.0 — 2026-10-06

**Добавлено**

- Референс-примеры (`reference/`): опись и правила чтения (`reference/README.md`) и
  пять разобранных экранов — два из B и три из A. На каждый экран — текстовый разбор
  (`screen.md`) и снятый из исходных макетов эталонный код (`context.tsx`).
- В описи README добавлен раздел «Референс-примеры (`reference/»)».
- **Исключение из правил каталога:** в `reference/*/context.tsx` намеренно
  присутствует код (правило «без кода, HTML, CSS и привязки к фреймворку» здесь не
  действует). Исключение ограничено папкой `reference/` и разово согласовано.

**Изменено** (обезличивание)

- Обезличены демонстрационные значения: имена клиентов и операторов, хостнеймы,
  имена узлов и аккаунта заменены на нейтральные (`Config_*`, `Rule_*`,
  `Node_A`/`Node_B`, `Account`, `host-*.example.org`, `REALM-*.EXAMPLE.ORG`,
  `node-*`, обнулённые числовые диапазоны). Размеры, цвета, шрифты, структура и
  число строк не затронуты.
